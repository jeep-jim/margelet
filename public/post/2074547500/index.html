Яндекс отдал на GitHub формат, который экономит до 20% серверных мощностей — называется YaFF Если вкратце: любой сервис на каждый запрос гоняет данные между серверами. Но прежде чем с ними работать, их нужно «распаковать» из компактного вида в понятный программе формат. Эта рутина называется десериализацией и незаметно съедает до 10% ресурсов дата-центра — компании буквально платят за серверы, которые заняты только распаковкой. Формат YaFF эту стадию пропускает: данные читаются напрямую из памяти, без лишних преобразований. На выходе — до 20% экономии процессора на тех же запросах. Решение уже обкатали на рекламной системе Яндекса (один из самых нагруженных сервисов компании), а теперь выложили в открытый доступ. Бонус: переписывать код не нужно — YaFF работает поверх привычного Protobuf 👍 Мы в МАХ 🤩
