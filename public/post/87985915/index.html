⚡️ Исследователи Яндекса представят в Сиднее решение одной из главных проблем при обновлении голосовых команд в умных устройствах — они научили модель новым командам БЕЗ «катастрофического забывания», при котором нейросеть начинает ошибаться на старых фразах. Обычно для этого дообучают всю нейросеть, из-за чего она начинает ошибаться на старых фразах. В эксперименте доля таких ошибок выросла с 2,71% до 69%. Инженеры Яндекса пошли другим путём: • Базовую модель полностью сохранили — старые сценарии не меняются. • Для новых команд подключили небольшую дополнительную ветку. • Она использует уже выученные моделью признаки, поэтому тяжёлую часть нейросети не приходится обсчитывать повторно. • Доля ошибок на новых командах снизилась с 6,46% до 4,37%, а точность старых осталась прежней. • Модуль требует примерно на 35% меньше ресурсов процессора и на 50% меньше оперативной памяти. • Система работает прямо на устройстве и без интернета. Архитектуру и результаты испытаний описали в статье Scalable Keyword Spotting via Modular Network Expansion, принятой на Interspeech 2026, одной из ведущих мировых конференций по технологиям речи. ⚡Провод
