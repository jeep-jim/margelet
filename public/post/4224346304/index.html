🚁 В ОАЭ обновили правила для воздушных такси и дронов-доставщиков Управление по регулированию телекоммуникаций и цифрового правительства ОАЭ (TDRA) утвердило новые правила использования радиочастот для воздушных такси, беспилотников и электрических летательных аппаратов нового поколения. 🤩Радиосвязь необходима не только для управления аппаратом. Она используется для навигации, отслеживания маршрута, связи с диспетчерами, предотвращения столкновений, передачи данных и взаимодействия дрона с наземной станцией. 🤩 Новые правила охватывают всю инфраструктуру Advanced Air Mobility: сами воздушные суда, центры управления, системы контроля воздушного движения и вертипорты, предназначенные для взлёта и посадки аппаратов с вертикальным взлётом. 📡 Воздушные такси и беспилотники смогут использовать мобильные сети лицензированных операторов ОАЭ. Для отдельных каналов управления предусмотрены специальные диапазоны частот и отдельные разрешения. 🤩 При этом операторы обязаны соблюдать требования GCAA, местных авиационных властей и законодательство ОАЭ о защите персональных данных. 🤩Важно: обновление правил радиочастот пока не означает автоматического разрешения на коммерческий запуск воздушных такси или доставки дронами. Для этого компаниям всё равно потребуется получить авиационные, технические и местные согласования. Новый регламент создаёт необходимую инфраструктуру для будущего, в котором беспилотные доставки и городские воздушные такси станут частью транспортной системы ОАЭ. #ОАЭ #Дубай #ВоздушноеТакси #Дроны #Технологии #ТранспортОАЭ #Инновации ОАЭ - Новости для бизнеса 😃😀 Bright Global Accounting в Max
