#Keyboards #Web #GitHub情报 ⌨️ 介绍两个基于不同地区真实轨道交通的在线打字测试项目 从若干年前的金山打字小游戏，到现如今层出不穷的开源打字测试项目，人们总是想办法让打字测试这件事变得更加有趣。今天介绍的两个项目，是基于两个不同地区的真是轨道交通，开发出来的打字测试网页 🚇 電車でタイピング 🔗：Web 👉 Features - 基于真实日本铁路网络 - 支持多种日语输入方式 - 探索玩法，逐步解锁车站和线路 - 多种模式，涵盖冒险、随机、山手线等 - 根据 WPM、准确率等综合评分 可以说 Train Typing 开创了这一模式的先河，它把整个日本铁路网络变成了游戏地图。玩家输入真实存在的车站名称（罗马字），沿着铁路一站一站前进，在练习打字的同时，也能熟悉日本铁路和地理情况 你可以选择随机到某一个站点开始打字测试，也可以围绕东京最经典的 JR 山手线来一个一圈循环，还可以指定起点和终点、反复练习某一段你喜爱的线路。可以说是打字测试爱好者和日本 JR 爱好者的双重福音 🚞 TAIWAN METRO TYPING 🔗：GitHub | Web 👉 Features - 涵盖台北、新北、桃园、台中与高雄捷运及轻轨共 13 条路线、275 笔站点座标 - 依真实站序与经纬度深度，支线以独立段承载 - 支持选线放大、运行选择方向、30 秒快打、全线挑战等多种模式 - 统计 WPM／CPM、正确率、完成站数与列车移动回馈 本项目参考了電車でタイピング的玩法和灵感，由台湾开发者量身定做了台湾路线。首页使用台湾行政区TopoJSON，并依WGS84经纬度投影捷运站与路线，对台湾和台湾轨道交通感兴趣的朋友可以试试 👀 实际上，两个项目能够落地，都离不开各自地区提供的轨道交通数据集。正如我之前说的那样，希望内地公共交通数据的来源能够更加丰富，将来也可以做一个内地版本的打字测试项目 📘 关联阅读： 1️⃣ 介绍两个有趣的地铁网页可视化项目 2️⃣ TypeLit：通过文学作品练习打字 3️⃣ Qwerty Learner：为键盘工作者设计的单词记忆与英语肌肉记忆锻炼网页 4️⃣ 简约、可自定义的打字测试项目 typing-cn 频道：@NewlearnerChannel
