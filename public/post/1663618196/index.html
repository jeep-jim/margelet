VDI。这个成本很多时候值得花：办公环境统一、资料集中管理，公司也更容易做权限、日志和设备管理。 基本结构 自己个人电脑桌面随便打开一个游戏或者视频网站挂机即可，搜查人员进来后可以马上关闭远程，保持自己游戏界面给他们看（集中多人办公的就算了因为没用，直接抓你没商量） 自己的个人电脑 ↓ 家庭 Wi-Fi / 路由器 ↓ 固定办公电脑 ↓ 云电脑 / VDI（如公司提供） ↓ 实际办公环境 在家庭局域网内使用远程桌面，延迟通常很低。 浏览器、聊天软件、Office、后台管理系统、表格等普通办公操作，基本可以流畅完成。 ① 准备两台 Windows 电脑 你需要： 电脑 A：办公电脑 用于运行工作软件、公司账号、办公环境等。 建议： 长期开机 禁止自动睡眠 最好使用网线连接路由器 可以关闭显示器 电脑 B：自己的个人电脑 平时坐在面前实际操作的电脑。 可以使用： Wi-Fi 网线 都可以。 ② 两台电脑连接同一个家庭网络 首先确保： 办公电脑和个人电脑连接的是同一个路由器。 推荐： 办公电脑 → 网线 → 路由器 个人电脑 → Wi-Fi → 路由器 并不是必须两台电脑都连接 Wi-Fi。 只要它们处于同一个能够互相访问的家庭局域网即可。 ③ 查询办公电脑局域网 IP【最重要】 在办公电脑上： 按： Win + R 输入： cmd 按回车。 然后输入： ipconfig 再按回车。 找到当前正在使用的网络适配器。 如果办公电脑使用网线，一般看： Ethernet 如果使用 Wi-Fi，一般看： Wireless LAN adapter Wi-Fi 找到： IPv4 Address 例如： 192.168.1.123 那么： 192.168.1.123 = 这台办公电脑在家里的局域网 IP 把这个 IP 记下来。 后面个人电脑就是通过它连接办公电脑。 ④ 开启办公电脑远程桌面 在办公电脑打开： 设置 → 系统 → 远程桌面 打开： 远程桌面 同时确保办公电脑的 Windows 账户设置了登录密码。 远程连接时一般需要： Windows 用户名 + 密码 ⚠️ Windows 家庭版注意 Windows Home 家庭版通常不能直接作为 Windows 自带 RDP 的被控主机。 如果你进入： 设置 → 系统 找不到正常可用的「远程桌面」功能，需要先检查 Windows 版本。 通常建议办公电脑使用： Windows 11 Pro ⑤ 禁止办公电脑自动睡眠 这一步非常重要。 办公电脑进入睡眠后，远程连接可能直接断掉或者无法再次连接。 进入： 设置 → 系统 → 电源和电池 → 屏幕、睡眠和休眠 将： 电脑进入睡眠 设置为： 从不 但是显示器没有必要一直亮。 例如可以设置： 5 分钟后关闭显示器 这样： 显示器黑屏 ✅ 电脑继续运行 ✅ 远程桌面继续工作 ✅ ⑥ 使用个人电脑连接办公电脑 来到自己的个人电脑。 按： Win + R 输入： mstsc 按回车。 Windows 会打开： 远程桌面连接 在： 计算机 这里输入刚才办公电脑的局域网 IP。 例如： 192.168.1.123 点击： 连接 然后输入办公电脑的： Windows 用户名 + 密码 连接成功之后，你看到的就是办公电脑桌面。 之后： 键盘 鼠标 浏览器 Office 聊天软件 后台系统 全部都可以直接操作。 ⑦ 建议固定办公电脑 IP 这一步虽然不是必须，但是非常推荐。 因为： 192.168.1.123 这个地址通常是路由器通过 DHCP 自动分配的。 今天可能是： 192.168.1.123 过段时间可能变成： 192.168.1.124 这样原来的地址就连接不上了。 最省事的方法是进入路由器后台。 找到类似： DHCP Reservation Address Reservation Static Lease IP & MAC Binding 不同品牌路由器名字可能不同。 找到办公电脑，然后把它绑定固定 IP。 例如： 192.168.1.123 以后办公电脑无论重启多少次，都尽量保持这个地址。 个人电脑以后只需要： Win + R ↓ mstsc ↓ 192.168.1.123 ↓ 连接 即可。 ⑧ 公司有云电脑的话更适合 如果公司本身提供： 云电脑 VDI 虚拟桌面 远程办公桌面 那么可以继续套一层： 个人电脑 ↓ 家庭局域网 ↓ 固定办公电脑 ↓ 公司云电脑 / VDI ↓ 实际业务环境 这样相当于分成三层： 第一层 个人电脑 你的个人软件和日常环境。 第二层 固定办公电脑 负责公司账号、远程入口、办公客户端等。 第三层 云电脑 / VDI 真正运行公司业务系统、文件和办公环境。 对公司来说，这种模式其实也比较好管理。 公司可以统一： 账号 权限 文件 软件 日志 备份 设备管理 远程办公人数多的话，云电脑的成本很多时候不能省。 🔐 安全注意事项 本教程说的是： 同一个家庭网络内部的局域网远程控制。 因此正常情况下： ✅ 不需要公网 IP ✅ 不需要购买远程软件 ✅ 不需要端口转发 ✅ 不需要把 3389 开放到互联网 ✅ 办公电脑显示器可以关闭 ✅ 办公电脑可以长期运行
