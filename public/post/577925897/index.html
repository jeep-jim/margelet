Заправки на трассах - автоматы для дальнобойщиков и путешественников покупающих цветы по пути домой. Круглосуточный режим критичен для ночных рейсов. Средний чек 550₽. АЗС с трафиком 800-1500 авто/сутки дает 15-35 продаж. Партнерство с сетями заправок открывает 50-120 локаций одновременно с минимальной арендой.
