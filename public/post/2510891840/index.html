Сотрудники ЦОНа помогали иностранцам получать ИИН без приезда в Казахстан…

Сотрудники ЦОНа помогали иностранцам получать ИИН без приезда в Казахстан В Астане раскрыли схему незаконного оформления ИИН для иностранцев. Как сообщили в АФМ, в 2024–2025 годах гражданам других стран помогали получать казахстанские идентификационные номера дистанционно, хотя по закону для этого нужно лично приехать в Казахстан и пройти биометрическую идентификацию. По данным следствия, в схеме участвовали сотрудники филиала госкорпорации «Правительство для граждан». Они вносили ложные данные в систему ЦОНа и оформляли фиктивные заявки. Поиск желающих велся через социальные сети, а деньги передавались через посредников банковскими переводами. Уголовное дело направлено в суд. t.me/Zanamiviehali
