🚀 На новой скорости Привет, сообщество! Мы завершили интеграцию нового торгового движка и запускаем обновлённую версию биржи — с более быстрой и стабильной обработкой ордеров. 27 июля в 04:30 (МСК) пройдут технические работы. На время работ будет недоступен быстрый обмен и спотовая торговля, а все открытые ордера будут отменены. ⚙️ Что поменяется После запуска баланс разделится на два: Trading — для торговли на бирже и Funding — для хранения средств. Новый движок - новый API • Изменится формат auth-токена — нужно выпустить новый, старые работать не будут. • Старый API (trade.xrocket.tg / trade.xrocket.exchange) будет отключен. • Баланс будет разделён на Trading и Funding. • Рыночные данные и обновления в реальном времени теперь через WebSocket. 🧠 Для бесшовного обновления сервисов, рекомендуем обновить интеграцию заранее. Все изменения уже доступны в testnet: • Testnet-бот • Testnet-биржа • Документация API • Swagger Новый движок — фундамент, на котором мы строим следующую версию торговли в xRocket: быстрее, надёжнее, мощнее.
