🌱 Астронавты смогут «выращивать» лекарства в космосе Разработан новый метод производства фармпрепаратов, который может позволить экипажам дальних космических миссий получать свежие лекарства по требованию с помощью растений. Идея особенно важна для полётов, где пополнение запасов с Земли невозможно или сильно ограничено. Растения могут стать компактной «биофабрикой» для нужных препаратов прямо на борту. Технология также может пригодиться на Земле — для недорогого производства лекарств в регионах с ограниченными ресурсами. 🔭 Тайны Космоса
