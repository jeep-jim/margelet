Почувствуй себя сотрудником Второй службы ФСБ. Мы восстановили прототип сервиса «Паук». Теперь можно самому изучить интерфейс ИИ-ассистента для спецслужбистов С января 2024-го по июнь 2025 года компания «Микорд» по заказу Второй службы ФСБ разрабатывала сервис «Паук» — нейросетевого помощника для спецслужбистов (полное расследование — здесь). Он должен был автоматизировать мониторинг СМИ, подготовку ежедневных сводок для руководства и поиск информации в открытых и внутренних источниках. Чтобы вы могли примерить на себя роль сотрудника «двойки», «Важные истории» восстановили кликабельный прототип «Паука» по найденным дизайн-макетам. Вы сможете открыть тот же интерфейс, который был разработан для сотрудников ФСБ: просматривать новости, собирать сводки для руководства, искать информацию о людях и событиях и работать с ИИ-помощником.
