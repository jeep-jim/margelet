Digitale ID – auf Rücken der Kinder eingeschleust! Um Minderjährige im Internet besser zu schützen oder gar ein Social-Media-Verbot durchzusetzen, benötigt man, laut der EU-Kommissionspräsidentin Ursula von der Leyen, eine digitale Altersprüfung. Patrick Wood schreibt dazu: „Zuerst die Altersüberprüfung für Minderjährige, dann eine Identität für alle! Tatsache ist: Technokraten brauchen die digitale Identität, damit ihr System funktioniert. Ohne sie ist die Technokratie tot. Programmierbares Geld, Sozialbewertung, algorithmische Regierungsführung – all das hängt von einer eindeutigen, verifizierten, maschinenlesbaren Identität für jeden Menschen ab. Beachten Sie, womit keines dieser Projekte beginnt: Kontrolle präsentiert sich niemals als Kontrolle. Die digitale ID kommt nie als Forderung daher. Sie kommt als Gefallen daher. Schützt die Kinder. Fangt die Betrüger. Sichert die Grenze.“ Großbritannien hat das Experiment als Erstes durchgeführt. Im Juli 2025 traten die Altersüberprüfungsvorschriften des „Online Safety Act“ in Kraft. Zum Schutz von Kindern mussten Erwachsene plötzlich amtliche Ausweise hochladen oder sich einem Gesichtsscan unterziehen, um z.B. auf legale Inhalte auf X zugreifen zu können. Zwei Monate später zeigte die Regierung ihre wahren Absichten. Der Premierminister kündigte eine nationale digitale ID an, die für das Recht auf Arbeit verpflichtend sein sollte. Im Januar 2026 kam die Wende: Großer Erfolg für die britische Zivilgesellschaft. Die Regierung in London hat die Pläne für eine Pflicht zur digitalen ID fallen gelassen! Jeder bisherige Sieg kam zustande, weil die Menschen ihre Stimme erhoben haben. Ab 2030 soll jeder EU-Bürger eine digitale ID haben, auch in der Schweiz ist die Einführung beschlossen! Der Widerstand gegen die verpflichtende digitale ID zeigt Wirkung. Also seid laut, solange noch Zeit bleibt! Mehr zum Thema 20.
