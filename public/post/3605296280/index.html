An open-source coding model has been released that outperforms Claude Opus 4.7 on key benchmarks DeepReinforce has released Ornith-1.0, a family of open-source models tailored for agent encoding. There are four variants: 9B Dense, 31B Dense, 35B MoE, and 397B MoE. Based on Gemma 4 and Qwen 3.5. The key idea of the model is that it learns not only to solve tasks but also to build scenarios for their solutions. Conventional models receive a ready-made "framework" of how to approach the task and work with it. Ornith generates and improves it during the training process. The flagship 397B version scored 77.5 on Terminal-Bench 2.1 and 82.4 on SWE-Bench Verified. Claude Opus 4.7 on the same tests shows 70.3 and 80.8. The 35B version outperforms Qwen 3.5-397B on Terminal-Bench, meaning a model eleven times smaller in parameters works better on this test. The 9B variant, which runs on regular hardware, outperforms Gemma 4-31B on several benchmarks. All models are available on Hugging Face.
