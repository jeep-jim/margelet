Сегодня горят три терминала WB. Два в Питере, один в Крыму. Противник буд…

Сегодня горят три терминала WB. Два в Питере, один в Крыму. Противник будет пытаться представить это как «удары по складам», где якобы хранятся компоненты для дронов. Но по факту цель куда шире. Это атаки не только на конкретные здания. Это попытка ударить по гражданской логистике, по бизнесу, по движению товаров, по людям, которые работают в этих цепочках, и по настроениям внутри общества. Когда под удар попадают такие объекты, последствия ощущают не военные, а предприниматели, водители, сотрудники складов, покупатели, семьи. Это не «точечные удары по компонентам». Это давление на экономику и гражданскую инфраструктуру. По сути — террор. Ответ на такие угрозы должен быть системным: защита ключевых логистических узлов, в том числе и на дальних рубежах, пересмотр размещения уязвимой инфраструктуры, усиление ПВО и повышение устойчивости всей экономики к подобным атакам.
