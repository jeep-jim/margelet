Яндекс KIT открыл API для интернет-магазинов. Платформа, которая позволяе…

Яндекс KIT открыл API для интернет-магазинов. Платформа, которая позволяет бесплатно запускать интернет-магазины для продажи физических товаров, теперь поддерживает подключение внешних систем, даже если они не входят в список готовых интеграций. Это поможет автоматизировать работу магазина без привязки к конкретным технологиям или языкам программирования. Через API можно загружать товары из любых ERP- и PIM-систем, обновлять остатки и цены, передавать заказы в CRM, получать уведомления и выстраивать собственные сценарии работы. Инструмент поддерживает большинство разделов магазина — от товаров и складов до скидок, промокодов и коллекций. Подключение по API пригодится разработчикам, digital- и ecommerce-агентствам, а также компаниям с собственной системой учёта или большим ассортиментом товаров. @retailrus
