Теперь компания пошла на сделку с правительством США и согласилась жёстко отслеживать риски, «сотрудничать с властями по безопасности». Условия — использование через облако Anthropic, то есть прозрачность запросов пользователей для всех, очевидно, включая спецслужбы США — американцы сообразили, как использовать свои передовые технологии. Другими словами, Anthropic сдал своих пользователей правительству США в обмен на выход на рынок. Олег Царёв. Telegram и Max.
