Microsoft выпустила рекордное количество патчей при помощи ИИ По данным Krebs on Security, Microsoft выпустила рекордные 570 патчей безопасности, задействовав ИИ для поиска уязвимостей в коде. Среди обновлений — две критические уязвимости «нулевого дня», которые хакеры использовали до того, как компания узнала об их существовании. Одна из ошибок затрагивает Windows Server и позволяет злоумышленникам повысить свои права от обычного пользователя до системного администратора. Вторая уязвимость касается сервера SharePoint, который хакеры использовали для компрометации организаций, о чём официально предупредило агентство CISA. По словам руководства, объём патчей продолжит расти, так как ИИ помогает выявлять ошибки, десятилетиями скрывавшиеся в коде Windows.
