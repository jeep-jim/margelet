Snack It — копилка визуалов для промтов Простой способ заставить ИИ генерить картинки в нужном стиле, не мучаясь с подбором слов к промту. Этот сервис сохраняет изображения в нужном стиле из соцсетей или любого сайта — прямо в браузере одним кликом. Референсы накапливаются в одном месте, чтобы потом их можно было разом «залить» в промт для нейросети. Сильно экономит время и нервы — с большим набором визуалов-примеров ИИ практически наверняка даст нужный результат. Сервис бесплатный: просто ставите расширение для Chrome, и всё работает без регистрации. Базовые функции (сохранять картинки, организовывать галереи и генерировать промты) доступны навсегда. #бесплатный #визуал
