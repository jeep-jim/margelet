Вот пути в настройках: 📱 Для iPhone: Настройки → Сотовая связь → Параметры данных → включите тумблер «Роуминг данных». 📱 Для Android: Настройки → Сеть и Интернет (или SIM-карты и мобильные сети) → выберите свою SIM → активируйте «Роуминг данных». ✅ Готово! Теперь связь переключится автоматически в случае сбоев.
