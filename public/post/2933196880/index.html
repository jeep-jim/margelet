🚨 Губернатор Ставрополья: предложения жителей по ситуации с топливом рассмотрят на оперштабе Губернатор Владимир Владимиров сообщил, что внимательно изучает комментарии жителей по ситуации с топливом. По его словам, все конструктивные предложения будут проанализированы и рассмотрены. Основные заявления: • Обсуждается идея выделить отдельные АЗС для спецтехники, работающей по транспортным картам. • Крупные агрохолдинги, как правило, заранее создают запасы топлива перед уборочной кампанией. • Для небольших сельхозпредприятий определен региональный оператор, который обеспечивает заправку техники. • Информация о попытках отдельных людей получать топливо по различным схемам уже передана для рассмотрения на оперативном штабе. Также губернатор отметил, что понимает эмоции жителей и заверил, что все разумные предложения будут изучены для принятия возможных решений.
