Сегодня почти 3 тысяч саратовских выпускников сдают ЕГЭ по трем предметам Школьники сдают ЕГЭ по биологии, географии и письменную часть по иностранному языку. В области организовано 53 пункта проведения экзаменов. Экзамен по биологии выбрали 1 875 выпускников. На выполнение работы отводится 3 часа 55 минут, она включает 28 заданий. Географию сдают 344 участника, на экзамен отведено 3 часа, работа состоит из 29 заданий. Письменную часть ЕГЭ по иностранным языкам сдают 697 выпускников, из них английский язык выбрали 686 человек, немецкий – 9, французский - 2. Установленный минимальный балл по биологии составляет 36 баллов, по географии – 37, по иностранным языкам – 22 балла. Результаты экзаменов по биологии и географии выпускники смогут узнать не позднее 30 июня, по иностранным языкам – не позднее 2 июля. 😊 Мы в MAX | Мы в TG | Прислать новость
