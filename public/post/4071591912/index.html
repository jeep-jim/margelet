Уважаемые пассажиры! В связи с ранее действовавшими ограничениями в воздушном пространстве московского авиаузла в настоящее время значительно корректируется расписание рейсов в столицу и по ряду других направлений. В терминале временно увеличено количество пассажиров, ожидающих вылета. Для них в Пулково действуют следующие меры поддержки: • агенты по гостеприимству для оперативного информирования и помощи; • чат-бот аэропорта Пулково в MAX для отслеживания статуса рейса; • круглосуточная комната матери и ребенка для пассажиров с детьми до 7 лет; • круглосуточная медицинская помощь; • опенспейсы для пассажиров с особыми потребностями; • бесплатные зарядные станции для мобильных устройств; • бесплатный Wi-Fi. 🔄 Обращаем внимание, что все пассажиры могут покинуть чистую зону даже после прохождения предполетных процедур. Для этого необходимо проследовать обратно по маршруту прохождения контроля, предъявив посадочный талон. Посадочный талон останется действительным, повторная регистрация на рейс не потребуется. Пассажирам отмененных рейсов мы рекомендуем покинуть терминал для обеспечения комфортного размещения пассажиров, ожидающих вылета. По вопросам возврата денежных средств и переоформления билетов следует обращаться в авиакомпанию. ❗️📱 Получить актуальную информацию о рейсе, а также управлять бронированием можно онлайн — через личный кабинет вашей авиакомпании. 🚉 Для пассажиров, которые хотят воспользоваться альтернативным видом транспорта, в терминале работает касса РЖД. Она находится на 2 этаже общедоступной зоны, рядом с кассами авиакомпаний. Благодарим за понимание! Поддержите Пулково бустами | Подписывайтесь на канал в МАХ
