​🤝 Студия производства контента для малого бизнеса «Медиа-Крафт» Создание фото и видео для малого бизнеса, у которого нет своего маркетолога. Основная услуга — выездная съёмка на день с готовым контентом на месяц вперёд. Целевая аудитория •Локальный бизнес (кафе, салоны красоты). •Частные специалисты (репетиторы, тренеры). •Стартапы. Ключевые услуги 1. «Контент-день»: фотосессия продукта, процесса работы и команды. 2. Создание коротких роликов (Reels/Shorts) для соцсетей. 3. Разработка единого стиля для ленты клиента. Финансовое планирование Стартовый капитал ~10 000 руб. (на аренду света и рекламу) На что пойдут средства: •Аренда базового оборудования (свет, отражатели) на первый месяц •Оплата подписки на видеоредактор •Минимальные расходы на рекламу для поиска первого клиента Прибыль через 3 месяца ~85 000 руб./мес. Источники дохода: •Пакет «Контент-день», ежемесячное абонентское обслуживание (ведение соцсетей) •Продажа дополнительных услуг (монтаж дополнительных роликов, написание статей). План запуска 1. Сделать портфолио, сняв знакомого предпринимателя бесплатно. 2. Создать страницы в соцсетях и публиковать кейсы «было/стало». 3. Предложить свои услуги 5–10 локальным бизнесам. 4. Запустить таргетированную рекламу на владельцев бизнеса. 🤑 Акула Бизнеса
