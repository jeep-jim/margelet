✨ Nova Lake-S засветился в Linux с графикой Xe3P Intel добавила в Linux новые PCI-идентификаторы для встроенной графики Xe3P в будущих настольных процессорах Nova Lake-S. В патчах фигурируют сразу семь ID: 0xD740, 0xD741, 0xD742, 0xD743, 0xD745, 0xD74A и 0xD74B. Это не значит, что у Nova Lake-S будет семь разных «встроек». Часть ID может относиться к инженерным образцам, тестовым конфигурациям или ранним версиям, которые не дойдут до розничных процессоров. В тех же изменениях появилась поддержка DC3CO - режима, который отключает части графики в простое для снижения энергопотребления. Ещё добавили CMTG для лучшей синхронизации дисплеев в системах с несколькими экранами. #Intеl
