Российский бизнес за один квартал использовал больше ИИ-токенов Яндекса,…

Российский бизнес за один квартал использовал больше ИИ-токенов Яндекса, чем за весь прошлый год. Во втором квартале компании прогнали через API Yandex AI Studio 398 млрд коммерческих токенов — вдвое больше, чем кварталом ранее, и на 70% больше результата за весь 2025-й. Тренд очевиден: ИИ начали встраивать в обычную работу, разработку и внутренние процессы. Это уже не эксперимент, а инфраструктура для рабочих процессов. Для этого компании используют Yandex AI Studio и SourceCraft — платформы для создания агентов и автоматизации процессов, в том числе разработки. На фоне этого выручка Yandex B2B Tech выросла на 29% — до 15,3 млрд рублей, а ИИ-сервисами уже пользуются больше трети крупных клиентов.
