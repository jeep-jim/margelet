🌿Калатея Network (Goeppertia musaica 'Network') Калатея Network — одна з…

🌿Калатея Network (Goeppertia musaica 'Network') Калатея Network — одна з найнезвичайніших представниць свого роду. Її головна особливість — унікальний геометричний візерунок на листі. Зелені та жовтуваті прожилки перетинаються під прямими кутами, створюючи ефект мозаїки або комп'ютерної сітки, завдяки чому рослина й отримала назву «Network». Попри репутацію примхливих калатей, цей сорт вважається більш витривалим. 🌿 Освітлення: яскраве розсіяне світло або легка півтінь. Пряме сонце може пошкодити листя й зробити візерунок менш виразним. 💧 Полив: ґрунт має бути злегка вологим. Поливайте лише м'якою відстояною або фільтрованою водою кімнатної температури. 💦 Вологість повітря: не менше 50–60%. Якщо кінчики листків підсихають — повітря занадто сухе. Допоможе зволожувач або піддон із вологим керамзитом. 🌡 Температура: оптимально +18...+25 °C. Рослина не любить протягів і різких перепадів температур. #калатея 🪴Квіткова душа🪴 👉 Навігація по каналу
