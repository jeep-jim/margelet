Комплексы ZALA приняли участие в масштабных учениях по защите морских руб…

Комплексы ZALA приняли участие в масштабных учениях по защите морских рубежей, прошедших в рамках международного форума «Крылья Сахалина». По сценарию учений безэкипажный катер атаковал условный объект в заливе Мордвинова. Для обнаружения цели представителями силового ведомства в район был направлен БПЛА ZALA Z-16. Для управления операцией специалисты ZALA развернули мобильный командный пункт на базе цифровой платформы 4Z1. В едином цифровом контуре были объединены данные беспилотных комплексов разных типов, радиолокационной станции и системы маяков. Управление всеми силами осуществлялось из ситуационного центра с использованием суверенной системы связи и навигации ZALA «ГЕОКОСМОС». ZALA Z-16 оперативно обнаружил и идентифицировал БЭК-мишень, после чего в режиме реального времени передал информацию в командный пункт. На основе полученных данных представителями силового ведомства было принято решение о применении ударного БПЛА по условному противнику. Контроль результатов применения выполнен с помощью ZALA Z-16. @ZalaAero
