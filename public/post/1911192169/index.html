Wieder ein Beitrag zum Kapitel "S`passiert ja nix`... 👇 So lief es unter der BIDEN-(globalfaschistisch-gesteuerten)US-Regierung: "Über 1,5 Millionen Menschen, die dem Meldesystem für Impfnebenwirkungen (VAERS) eine COVID-19-Impfschädigung gemeldet haben, können nicht einmal eine Entschädigung aus dem staatlichen Programm beantragen, das COVID-19-Impfschäden abdeckt – denn das Programm deckt nur Todesfälle oder schwere körperliche Verletzungen ab. Gemäß der Definition der Regierung für schwere körperliche Verletzung muss die Verletzung entweder lebensbedrohlich sein, zu einer dauerhaften Beeinträchtigung einer Körperfunktion oder einer dauerhaften Schädigung einer Körperstruktur führen oder einen `medizinischen oder chirurgischen Eingriff erfordern, um eine dauerhafte Beeinträchtigung einer Körperfunktion oder eine dauerhafte Schädigung einer Körperstruktur zu verhindern'." (Ray L. Florse, Suzanne Burdick - 21. August 2026) 😱😱😱 Und das ist es, was Robert F. Kennedy jr. jetzt angeht.... 👇 "US-Gesundheitsminister Robert F. Kennedy Jr. bereitet die Einleitung eines Regelungsverfahrens vor, das es für Menschen, die durch COVID-19-Impfstoffe geschädigt wurden, erheblich erleichtern könnte, eine Entschädigung von der Bundesregierung zu erhalten. Dies wäre eine der bislang weitreichendsten Änderungen am Programm für Impfschäden. Laut einer Regulierungsagenda der Bundesregierung plant das US-Gesundheitsministerium (HHS), im November einen Verordnungsentwurf vorzulegen, der eine offizielle Schadensliste für COVID-19-Impfstoffe festlegen würde. Der Entwurf würde einer öffentlichen Konsultationsphase unterzogen, die voraussichtlich bis Anfang 2027 dauern würde, bevor eine endgültige Verordnung in Kraft treten könnte. Kennedys Vorschlag sieht die Einführung einer Tabelle vor, in der Schäden aufgeführt sind, von denen die Regierung annimmt, dass sie durch abgedeckte COVID-19-Maßnahmen, einschließlich Impfstoffen, verursacht wurden." 🔥🔥🔥 https://childrenshealthdefense.org/defender/over-1-million-covid-vaers-reports-cicp-fail-accept-compensation-applications/
