#macOS #iOS #APP #Music 🎛 Tutti：一个声音，响遍全场 | macOS 新音频控制中枢 🔗：GitHub | Web | Releases | Demo 👉 Features - 多设备输出， 即时组建 CoreAudio 聚合设备 - 每个输出有独立滑块和静音，热插拔不断音 - 单个 App 音频控制 - 提供 Now Playing 卡片 - 支持蓝牙自行重连、耳机电量显示 - 立体声配对与左右平衡 / 单个 App 输出路由 / 单设备延迟微调 / iPhone 遥控（Pro 功能） 📢 之前曾多次说过，macOS 许多自带功能不够完善，导致了第三方市场蓬勃发展。今天介绍的音频中枢控制器就是一个尚未被 Apple 完善的一个很好的例子，为了让难用的「音频 MIDI 设置」变好，大家开发了 Background Music、SoundSource 等专业音频软件，精准控制声音怎么来、到哪去 📻 Tutti 是这一流派的全新开源力作，除了处理上面的问题之外，开发者还非常关心怎么「让多个设备一同发声」。刚看到这个核心卖点的时候，我还是非常不能理解的，为什么要让许多设备同时响起？开发者给出了几个场景： ① 多人 / 不同设备 / 同时听 ② 直播与录制用耳机监听的同时，把声音播给观众或采集卡 ③ 多房间播放 ④ 沙发遥控，在 iPhone 上切预设、挑音箱（Pro 功能） 💡 你可以清晰地看出，这个软件的受众是对于听音有着特殊需求的人群。作为普通用户，我们利用 Tutti 调节 App 音频或使用蓝牙控制功能就很好了，这些都是免费的。我的需求和开发者截然相反：想把多个物理设备接入同一中枢控制、同一音频设备播放。实现方式是，把电视、Mac、唱片机通过线缆接入数播（家用音频中枢），再输出到一对大落地音箱，这套方案最迟明年能够落地，到时再和大家详细分享 👀 Tutti 目前的问题是不支持 AirPlay 多输出组推流，这是 Apple 官方的限制。官方的 Roadmap 是在 Tutti 内直接路由 AirPlay，不必先去控制中心，直接在面板里挑选与切换 AirPlay 接收端。听音系统是一套复杂的系统，由软件和硬件共同组成，欢迎大家分享你目前在用的音频链路 📘 关联阅读： 1️⃣ macOS 知名音量管理工具 SoundSource 迎来大更新 2️⃣ 我如何构建本地乐库、用 MusicHabor 把控自己的音乐输入 3️⃣ Genelec G One 与 Pro-Ject E1：用音乐润色生活 频道：@NewlearnerChannel
