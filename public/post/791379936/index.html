Минцифры готовит план по полному убийству анонимности в интернете Минцифры готовит план, после которого вычислить владельца сайта, сервера или выделенного IP-адреса станет куда легче, чем сейчас. По словам инсайдеров, обязательная идентификация клиентов хостинг-провайдеров через Госуслуги — только следующий этап общей схемы: государству нужен не просто контроль доменов, а прямая связка между человеком, его сервером, IP, сайтом и технической инфраструктурой. Сейчас у хостеров ещё остаются разные способы подтверждения клиента: почта, банковская карта, договор, корпоративные данные. Новый подход оставляет главным ключом подтверждённую учётную запись Госуслуг. После этого каждый выделенный IP можно будет привязать к конкретному пользователю или компании. Для силовиков это резко упрощает цепочку: жалоба, IP, хостинг, Госуслуги, паспортные данные, адрес и телефон владельца. В Минцифры и Роскомнадзоре обсуждают единый контур: домены в зонах .ru, .рф и .su уже привязывают к подтверждённой личности, теперь туда добавляют хостинг и IP-адреса. Следующий шаг — автоматическая сверка данных хостеров с реестрами блокировок, запросами МВД, ФСБ и Роскомнадзора. Тогда для поиска владельца ресурса не потребуется долгая техническая экспертиза: достаточно будет поднять связку «IP — хостер — Госуслуги». ❤ INSIDER-T - подписаться
