🛠 Windows 11 сможет восстановиться даже после серьёзного сбоя Microsoft начала тестировать Cloud Rebuild - новый способ восстановления Windows 11 через интернет. В отличие от функции «Вернуть компьютер в исходное состояние», он работает даже в случаях, когда система больше не загружается. Cloud Rebuild скачивает из Windows Update чистый образ Windows и необходимые драйверы, а затем автоматически переустанавливает систему без загрузочной флешки или локального образа восстановления. Для работы потребуется только подключение к интернету. Пока функция доступна участникам программы Windows Insider в канале Experimental. В стабильных версиях Windows 11 она должна появиться в ближайшие месяцы. #Micrоsоft
