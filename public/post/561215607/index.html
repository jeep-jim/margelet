Получаем портрет вайбкодера от Claude Code: собрали промт для анализа своего подхода к работе с ИИ. Составь психологический портрет моего подхода к разработке и работе над задачами на основе всех логов наших сессий — как я формулирую команды, что повторяю, как правлю курс, какой тон. Для задачи используй скрипт, который: - берёт только мои реплики (type=user, role=user), выкидывает tool-результаты, system-reminder, command-обертки, task-notification, isMeta; - дедуплицирует по uuid и по тексту; - отдельно выделяет «голос» — короткие набранные команды (≤60 слов, без вставленных код-блоков/URL), чтобы вставки-спеки не забивали статистику. Считай по голосу и по всему корпусу: объем (сессий, реплик, слов, слов/реплику), топ-императивы по корням, первое слово реплики, и маркеры — verify/проверь, категоричность, самокоррекция, пожалуйста/спасибо, мат. На выходе: портрет-анализ моего подхода к работе. Что говорят цифры, включая слабые стороны. Правила: опирайся только на реальные числа из логов, без подхалимства. Ждем, когда такие отчеты будут подходить для резюме.
