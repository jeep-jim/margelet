Липецкие разработчики научили дрон искать людей под завалами по звуку🔊 С…

Липецкие разработчики научили дрон искать людей под завалами по звуку🔊 Студент ЛГТУ Сергей Зуев разработал модуль для беспилотников, который позволяет обнаруживать людей под завалами по звуковым сигналам. Проект AIRSONIC SCOUT стал одним из семи победителей федерального конкурса «Студенческий стартап». Как сообщают «Липецкие новости» со ссылкой на региональное правительство, шесть из семи победивших проектов разработали студенты и аспиранты Липецкого государственного технического университета. Все авторы получат по 1 млн рублей на дальнейшее развитие своих разработок. AIRSONIC SCOUT представляет собой модуль с искусственным интеллектом для установки на беспилотные летательные аппараты. Система позволяет использовать дрон для поиска людей в условиях, где проведение спасательных работ затруднено, в том числе при обрушении зданий и разборе завалов. Еще одним победившим проектом стал мягкий роботизированный манипулятор PneuSens, созданный студентом Александром Романовым. Устройство предназначено для работы в непосредственной близости от человека и может применяться при разборе завалов, медицинских процедурах и других задачах, где использование жестких механических конструкций может быть опасным.
