🐶 Ghidra — фреймворк АНБ для реверс-инжиниринга ПО | Привет, друг. На связи Эллиот. Ghidra — это фреймворк для реверс-инжиниринга, создан и поддерживается Исследовательским управлением Агентства национальной безопасности США. Фреймворк включает набор высококачественных инструментов для анализа ПО на различных платформах Windows, macOS и Linux: 1. дизассемблирование; 2. ассемблирование; 3. декомпиляция; 4. построение графиков; 5. скриптование; 6. а также сотни других функций. — Ghidra поддерживает разные наборы инструкций CPU и исполняемые форматы, работает в интерактивном и автоматическом режиме.
