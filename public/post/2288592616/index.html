📢 Sl8 Wallet Update We continue to improve the wallet and regularly work on both visible features and the smaller details that make everyday use more convenient. The latest version introduces a new option that allows you to choose how your total staking value is displayed - either including rewards or showing only the principal amount. Your selection is saved automatically for future sessions. We have also improved the staking section. Total values, staking counts, and percentage indicators now correctly reflect the filters you apply and display only the data that is currently visible on your screen. Several staking-related details have been corrected as well. Renewal status, auto-renewal information, payment history, and redemption dates are now displayed more accurately. In the liquidity section, we fixed an issue that could cause pool TVL to display as $0. It now shows the actual value. We also resolved a problem where the Auto-Compound indicator could disappear after a screen refresh. The assets section has received improvements too. Asset sorting by value now works correctly, and balance information on asset detail pages now displays live values instead of incorrect zero balances. We also spent time improving overall reliability. Error messages are now clearer and provide more useful information, balances refresh immediately after transactions are sent, and session loading issues now display the proper error screen instead of an incorrect activation screen. Thank you to everyone who continues to share feedback and report issues.
