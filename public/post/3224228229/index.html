Apple сделает буфер обмена iPhone доступным для ПК на Windows По данным MacRumors, Apple планирует разрешить пользователям копировать и переносить контент с iPhone на ПК с Windows в ответ на требование Microsoft в ЕС. Новая функция восполнит отсутствие кроссплатформенного аналога Universal Clipboard для обмена данными между iPhone и Windows. Чтобы реализовать эту возможность, Microsoft задействует фреймворк AccessorySetupKit — тот же инструмент, который Meta* ранее применяла в ЕС, чтобы добиться совместимости устройств. Apple планирует завершить разработку проекта осенью 2027 года, после чего состоится его полноценный публичный релиз. Meta* - признана экстремистской организацией на территории РФ.
