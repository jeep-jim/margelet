Моя акция на WB - в помощь при перегрузке региона На WB можно создать собственную акцию и дать дополнительную скидку только для выбранного региона. Как запустить: Заходим в Мои акции → календарь акций. Создаём акцию: указываем название, процент скидки и даты. Учитываем, что акция стартует не сразу - WB нужно несколько дней на обработку. Настраиваем товары не по артикулам, а по условиям: цена, скидка, дни на WB, бренд, категория. Выбираем аудиторию по региону: область, край или республика, не конкретный склад. Как проверить результат: После завершения периода смотрим закрывающие документы. В детализации финансового отчёта будут столбцы: - ID собственной акции продавца с дополнительной скидкой - Размер дополнительной скидки по собственной акции продавца, % Если продажа прошла по акции - там появятся ID и процент скидки. Стоимость сей прелести +1% к комиссии с продаж товаров, которые купили со скидкой по опции. Инструмент полезен, когда нужно точечно простимулировать продажи в конкретном регионе, не снижая цену по всей стране.
