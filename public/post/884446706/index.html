В Японии придумали двойной пивной бокал для зожников — он вынуждает чередовать алкоголь с водой. Одна половина предназначена для пива, другая — для воды. Пить только из одной части не получится: бокал потеряет равновесие и опрокинется. Такое изобретение помогает поддерживать водный баланс и пить медленнее, снижая риск похмелья на утро. 🔥 Биохакеры / Мы в МАХ
