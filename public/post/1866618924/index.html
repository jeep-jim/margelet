Anthropic утверждает: Alibaba продолжает в больших масштабах дистиллировать Claude для обучения Qwen. Источник - Bloomberg. Anthropic обвиняет операторов, связанных с Alibaba, в масштабной кампании по незаконному доступу к Claude через почти 25 000 фейковых аккаунтов. По данным Bloomberg, Anthropic заявляет, что в рамках этой кампании с апреля по июнь было сгенерировано 28,8 млн обменов с Claude. Целью были способности вроде software engineering и agentic reasoning. Компания считает это частью более широкой схемы «adversarial distillation», когда китайские лаборатории якобы собирают ответы американских frontier-моделей, чтобы обучать конкурирующие системы за гораздо меньшие деньги.
