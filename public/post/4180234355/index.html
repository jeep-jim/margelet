Школьница из Хабаровска изобрела метод ускорения селекции подсолнечника.…

Школьница из Хабаровска изобрела метод ускорения селекции подсолнечника. Ученица краевого центра образования Диана Зайкова разработала молекулярные маркеры для ускоренной селекции. Теперь юная хабаровчанка создает их вместе с единомышленниками. Работу над своим научным проектом Диана ведет в лабораториях центра «Сириус». Сам проект реализуется по реальному заказу индустриального партнера проекта. Научный эксперимент хабаровчанки сможет внести вклад в обеспечение продовольственной безопасности страны, считают специалисты. Вместо долгих лет полевых испытаний ученые смогут использовать быстрый ДНК-анализ для создания новых сортов. Диана стала участницей образовательной программы «Большие вызовы», которая помогает школьникам заниматься реальной наукой. В этом году из тысяч претендентов в программу прошли 400 одаренных школьников из России и Казахстана. Хабаровская школьница прошла отбор по направлению «Агропромышленные и биотехнологии».
