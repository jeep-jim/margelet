📢🌾 В Україні посилили критерії для отримання статусу критично важливого підприємства Міністерство економіки оновило вимоги до підприємств, які можуть отримати статус важливих для національної економіки та претендувати на бронювання працівників. 🔹 Для аграрного сектору мінімальну площу оброблюваних земель збільшено вдвічі — з 500 до 1000 га. 🔹 Мінімальний річний дохід агропідприємств підвищено з 20 млн грн до 40 млн грн. 🔹 Відтепер агропідприємства повинні надавати підтверджені податковими органами розрахунки для отримання відповідного статусу. 🌲 Для лісового господарства вимоги стали ще жорсткішими: мінімальна площа земель у постійному користуванні зросла з 500 до 2500 га. 💰 Також вперше запроваджено нові зарплатні критерії: ✔️ для компаній із понад 50 працівниками середня зарплата має бути не нижчою за середню по країні, помножену на 2; ✔️ для підприємств із понад 20 працівниками — на 3; ✔️ для компаній, що працюють у трьох і більше областях, встановлено додаткові вимоги щодо чисельності персоналу та сплати податків. 🚜 Водночас виробники української сільгосптехніки та обладнання також можуть отримати статус важливих для економіки, якщо їхня продукція входить до державної програми компенсації вартості техніки. 📌 Нові правила вже набрали чинності та суттєво підвищують вимоги до підприємств, які претендують на статус критично важливих для економіки України.
