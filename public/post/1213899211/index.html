✨ NVIDIA открыла CUDA для Windows on Arm перед выходом RTX Spark Предварительная версия CUDA Toolkit 13.4 впервые позволяет собирать CUDA-приложения непосредственно под Windows Arm64. Разработчики могут создавать нативные сборки на Arm-системах или кросс-компилировать их на обычных компьютерах с Windows x64. В комплект вошли компилятор, заголовочные файлы, библиотеки и компоненты среды выполнения. Вместе с инструментарием выпущен developer-драйвер 616.00 для тестовой платформы Microsoft Surface RTX Spark Dev Box. Релиз предназначен для переноса и проверки программ перед выходом устройств RTX Spark. Это предварительное ПО с неполной оптимизацией и известными ошибками, поэтому NVIDIA не рекомендует использовать его в рабочих системах. #Nvidiа
