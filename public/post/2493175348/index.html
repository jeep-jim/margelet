Появилась возможность управлять курсором языком – с помощью MouthPad Компания Augmental выпустила тачпад для рта MouthPad. Устройство представляет собой пластину, которая крепится на верхнюю челюсть. В зоне нёба находится чувствительная к касаниям панель – движения языком передаются на курсор. Каждую пластину изготавливают по индивидуальному слепку покупателя для точной посадки. Гаджет создан в первую очередь для людей с ограниченной подвижностью, но за $1400 (~109 000 рублей) его может приобрести любой желающий. Можно подарить кенту, чтобы в катках его рот был занят игрой, а не криками в войс. @ovsyanka
