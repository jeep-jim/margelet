Стрельба, наркотики, дискриминация: список нарушений для выдворения мигрантов из РФ расширили. Комитет Госдумы по госстроительству рекомендовал палате принять во втором чтении законопроект, расширяющий перечень административных правонарушений, за которые иностранцам помимо штрафа будет грозить высылка из страны.
