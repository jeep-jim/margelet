Microsoft готовится прикрыть пиратскую Windows. Компания собирается привя…

Microsoft готовится прикрыть пиратскую Windows. Компания собирается привязать KMS-серверы к аппаратной части компьютера, из-за чего привычные способы активации могут перестать работать. Новая система будет использовать TPM для проверки KMS-сервера: сверять его аппаратную идентичность и подтверждать, что сервер не был скомпрометирован. Предупреждения появятся в Windows Server 2025 уже в августе 2026 года, а в следующей версии Windows Server эта проверка станет обязательной. Если изменения внедрят полностью, популярный способ активации через поддельные KMS-серверы может уйти в прошлое. Обычных пользователей это пока не затронет. Пока. 🙂 📢Айтишная
