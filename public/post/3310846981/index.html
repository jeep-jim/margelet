Genspark открыла исходный код полноценного ИИ офиса для Windows и macOS GenOffice объединяет редактор документов, таблиц, презентаций и PDF. Это не урезанный просмотрщик, а полноценный набор инструментов для работы с файлами DOCX, XLSX и PPTX. Внутри встроен Genspark Super Agent. Он может провести исследование, обработать данные, написать документ или собрать презентацию. ИИ работает прямо с содержимым файла, а не просто отвечает в отдельном чате. Первую альфа-версию собрал один инженер за одну неделю. На работу ИИ моделей ушло около 10 тысяч долларов. Программа бесплатная, без рекламы и доступна на Windows и Mac с Apple Silicon. Исходный код открыт под лицензией Apache 2.0. Пока это ранняя версия. Разработчики предлагают пользователям сообщать о проблемах и за полезную обратную связь обещают больше 1000 кредитов Genspark. По сути, перед нами открытая альтернатива Microsoft Office, которую изначально создавали вокруг ИИ, а не добавляли его поверх старого интерфейса. dailyprompts.ru
