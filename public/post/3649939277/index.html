Пять звезд для котиков «Гостиницу» для вольной и одновременно сытой жизни…

Пять звезд для котиков «Гостиницу» для вольной и одновременно сытой жизни котиков устроил на своем приусадебном участке эксперт по недвижимости Дмитрий Таганов. «Недавно сделал для кошек отдельную резиденцию из семиметровой бытовки. Утепление, отопление с термостатом на 800 Вт, стены в коврах, лаз с тамбуром и вайфай-камера для контроля за этой бандой», — рассказал он в своем Instagram. Условия более чем комфортные: для сохранения тепла — шторы на магнитах и ковер на стене, для сытости — автоматическая кормушка и, конечно, свежая вода. Двери нового жилья открыты не только для подброшенных на его участок, но и для всех гуляющих в округе котов и кошек. Таганов назвал единственный недостаток «отеля» — это его цена. Если раньше такая бытовка стоила 35 тыс. рублей, то теперь кошачий комфорт обошелся в 120 тыс. рублей. Эксперт по недвижимости ведет блог о загородной жизни на 50 гектарах. Где они находятся, Таганов не уточняет: говорит, что раньше его «много показывали по ТВ», а теперь он уехал и «не мелькает». Если только на видео в своем блоге. Видео: Дмитрий Таганов, Instagram
