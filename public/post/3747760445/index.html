Полностью исчезнуть из интернета РЕАЛЬНО — мы собрали все способы, которые помогут подчистить почти весь ваш цифровой след 🔥🔥 Мы собрали полный чек-лист, который поможет убрать максимум информации о себе, а ещё нашли промпт для ChatGPT, который сделает большую часть работы за вас ➡️ Удалить себя из баз данных 🟣Эти сайты продают ваше имя, адрес и номер телефона кому угодно. Через разделы Opt-out можно подать запрос на удаление своих данных; ➖ Spokeo → Найдите себя → Откажитесь от услуг (Opt-out) → Отправьте запрос; ➖ Whitepages → Найдите свою запись → Запросите удаление; ➖ BeenVerified → Страница отказа от услуг (Opt-out page) → Отправьте запрос. ➡️ Удаление личной информации из Google 🟣Загуглите «запрос на удаление информации из Google». Подайте запрос на удаление страниц, где указан ваш номер телефона, почта или домашний адрес; 🟣Эта форма существует уже много лет, но почти никто ей не пользуется. По закону Google обязан рассматривать такие запросы. Обычно их одобряют в течение нескольких дней. ➡️ Найти и удалить забытые аккаунты 🟣В Gmail → Введите в поиске «подтвердите ваш email»; 🟣Каждый результат — это аккаунт, привязанный к вашей почте, о котором вы забыли. Войдите в аккаунт → Настройки → Удалить аккаунт. Один за другим. ➡️ Проверить, были ли ваши данные в утечках 🟣Найдите в поиске haveibeenpwned → Введите свой email; 🟣Сервис покажет все утечки данных, в которых фигурировала ваша информация. Скорее всего, вы найдете 5–15 утечек, о которых даже не подозревали; 🟣Также с помощью Verifalia и Have I Been Pwned можно узнать, в каких базах и утечках 10-летней давности до сих пор висят ваши пароли и аккаунты; ➡️ Отключить историю активности Google 🟣Мои действия → Удалить все → За все время → Все продукты; 🟣Отслеживание действий → Приостановить всё: ➖ История приложений и веб-поиска. Выкл. ➖ История местоположений. Выкл. ➖ История YouTube. Выкл. ➡️ Использовать одноразовые почты 🟣Используйте SimpleLogin, чтобы создавать одноразовые почты при каждой новой регистрации. Если одна из них утечет в сеть, просто удалите её. Ваша настоящая почта останется в безопасности; 🟣Также перейдите на Brave или Firefox. Оба браузера по умолчанию блокируют трекеры. Chrome — нет. ➡️ Удалить старые публикации 🟣X/Twitter: TweetDelete — автоудаление старых твитов; 🟣VK: история активности → фильтр по годам → удалить. А если не хочется искать всё вручную — есть решение проще. Нашли промпт для ChatGPT, который поможет: ➖ Найти упоминания вашего имени и никнеймов; ➖ Обнаружить забытые аккаунты; ➖ Проверить, какие данные уже утекли; ➖ Подготовить шаблоны запросов на удаление информации; ➖ Проверить фотографии на детали, раскрывающие место жительства или работы; ➖ Составить полноценный план по уменьшению цифрового следа именно под вас. ➡️ Промпт: You are a digital privacy specialist. Help reduce my public digital footprint using only legal, ethical methods. Location: [LOCATION] Names: [NAME VARIATIONS] Usernames: [USERNAMES] Emails: [EMAILS] Platforms: [PLATFORMS] Concerns: [ADDRESS / PHONE / POSTS / PHOTOS / SEARCH / DATA BROKERS / OTHER] Never ask for passwords, IDs, banking or other sensitive information. Create a prioritized plan to: • Find public pages, profiles, images and cached results. • Find forgotten accounts. • Classify everything: Delete / Remove / Private / Update / Monitor. • Find data brokers and explain removal. • Draft deletion/removal requests. • Remove search results where possible. • Audit social media for exposed personal data. • Remove metadata from files. • Check email breaches and recommend actions. • Create a monitoring routine. For every step include: • Action • Where • Search query/template • Difficulty • Privacy impact • Follow-up Ask only essential questions first. Be honest about what cannot be erased. Never recommend illegal actions, fake identities or deception. Finish with a table: Platform | Exposed data | Removal method | Date | Follow-up | Status Сохраняйте — пригодится каждому, кто хочет оставить как можно меньше инфы о себе 🌂
