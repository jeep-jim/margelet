Четыре спальни. Один характер. Ноль компромиссов. Новый проект Furni — 4BR апартаменты в The Grove, Dubai Creek Harbour. 🗣️ Клиент пришёл с конкретным референсом: неоклассика с элементами арт-деко, тёплая палитра, золотые акценты, насыщенный декор. Квартира — для себя, для жизни, надолго. Со своей эстетикой, сложившейся задолго до начала проекта. 👩🏻‍💻 Иногда задача дизайнера — не предлагать своё видение, а точно реализовать чужое. Уловить характер человека, его представление о доме — и воплотить его без потерь. ⏰ Две недели на подготовку и согласование дизайна. Мудборд, планировка, перепланировка кухни, частичная меблировка — включая мебель на заказ и детские комнаты. Результат — именно тот, который хотел клиент. Для нас это и есть главный критерий. Смотрим, что получилось? 👀 #design
