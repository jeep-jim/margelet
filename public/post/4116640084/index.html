# 菲律宾校园枪击案致3死20伤！总统府向每户遇难者家庭发放15万比索援助 菲律宾总统府6月23日宣布，将向独鲁万市校园枪击案中每名遇难者的家属提供15万比索经济援助。 这起枪击案造成3人死亡、20人受伤，两名涉案人员分别只有14岁和15岁，目前已由菲律宾社会福利与发展部负责看管。 菲律宾总统府新闻官克莱尔·卡斯特罗表示，枪击案中3名遇难者的家属，每户将获得15万比索援助，合计45万比索。 除经济援助外，菲律宾社会福利与发展部和卫生部还将为所有受事件影响的学生、家长、教师及相关人员提供心理辅导和社会支持服务。 案件发生于6月22日上午约9时，地点位于独鲁万市圣何塞国家高中。 枪击发生后，多名学生及其他人员被紧急送往医院救治。 官方确认，事件共造成3人死亡、20人受伤。部分家长在医院得知子女受伤后情绪崩溃，现场气氛十分沉重。 警方称，两名涉案人员分别为14岁和15岁，均属于未成年人。 两人目前由菲律宾社会福利与发展部看管，案件将按照未成年人保护及相关司法程序继续处理。 菲律宾国家警察表示，目前仍在调查枪击案的具体动机。 警方初步认为，两名涉案人员可能受到网络内容“严重影响”，但尚未公布他们浏览了哪些内容，也未确认网络信息与实际作案之间的具体关系。 枪击案发生后，菲律宾国家警察再次表态，支持将最低刑事责任年龄从现行的15岁下调至12岁。 这一立场预计将再次引发社会争议。 支持者认为，部分未成年人已经具备辨别严重犯罪后果的能力；反对者则担心，下调年龄会削弱对未成年人的保护，并掩盖家庭教育、校园管理及心理健康服务不足等更深层问题。 目前，菲律宾政府尚未宣布就此次案件调整相关法律，后续仍需由国会讨论决定。
