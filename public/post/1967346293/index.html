🔥Прорыв в науке: в Калмыкии научились очищать воду для скота с помощью овечьей шерсти Учёные и лаборанты Комплексной аналитической лаборатории РНПЦ КалмГУ разрабатывают экологичную технологию очистки воды для животноводческих хозяйств — в качестве основы используют отходы овечьей шерсти. В рамках госзадания Минобрнауки РФ специалисты изучили кератин — белок, который составляет основу шерсти племенных баранов. Эксперименты показали: кератин эффективно поглощает ионы магния и железа — именно они придают воде горький вкус. Сейчас учёные успешно выделяют чистый кератин и готовят его для создания фильтров. Цель проекта — разработать доступный и экологичный композитный сорбент для фильтровальных систем. Технология особенно актуальна для аридных регионов: она позволит превратить непригодную для поения скота воду в качественную — без использования дорогих аналогов. ⚠️ВАЖНО!
