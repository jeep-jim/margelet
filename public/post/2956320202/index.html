CVE-2026-56164 — затрагивает SharePoint Server и уже использующуюся в атаках. В компании объяснили, что отсутствие аутентификации для критически важных функций в Microsoft Office SharePoint позволяло неавторизованному злоумышленнику повысить свои привилегии; 2. CVE-2026-56155 — затрагивает Active Directory Federation Services (AD FS) и позволяет авторизованному атакующему локально повысить привилегии; 3. CVE-2026-50661 — позволяет обойти шифрование BitLocker и получить доступ к защищенным данным.
