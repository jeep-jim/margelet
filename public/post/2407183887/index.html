Забираем 9 обязательных настроек против краж — гений в Твиттере выкатил б…

Забираем 9 обязательных настроек против краж — гений в Твиттере выкатил буквально цифровой оберег от несчастных случаев. Просто включаем все функции за две минуты и больше никогда не волнуемся за телефон: он не пропадёт, а воры не смогут его взломать или перепрошить. Карманная крепость с сим-картой внутри строится так: 1. Защищаем устройство: Настройки → Face ID и код пароль → Защита краденного устройства → Всегда Если грабители захотят сменить Apple ID и отключить Локатор, смартфон проверит лицо владельца. 2. Отключаем «Пункт управления»: Настройки → Face ID и код-пароль → Доступ с блокировкой экрана → отключить «Пункт управления». Включить Авиарежим с экрана блокировки больше нельзя. 3. Отключаем «Аксессуары» на заблокированном экране: Настройки → Face ID и код-пароль → выключаем «Аксессуары». Блокировка длится больше часа — USB-аксессуары больше к смартфону не подключить: никакого физического взлома. 4. Пароль из 6 знаков: Настройки → Face ID и код-пароль → Сменить код-пароль Больше код — больше мороки для воров. 5. Включаем «Локатор» и отправку последней геопозиции: Настройки → Ваше имя → Локатор → Найти iPhone → включаем все три тумблера 6. Ставим PIN на SIM-карту: Настройки → Сотовая связь → PIN-код SIM-карты → включаем Сим-карта блокируется, если её вставить в другой телефон. Теперь перехват SMS из банков и прочих сервисов невозможен. 7. Включаем автообновление ПО: Настройки → Основные → Обновление ПО → Автообновление → включаем все Компании регулярно работают над безопасностью ПО, а вы пожинаете плоды их работы. 8. Удаляем старые доверенные устройства: Настройки → Ваше имя → Листаем вниз → Удаляем устройства, которыми не пользуетесь. Меньше путей для получения кодов доступа к вашей учётной записи. 9. Проверяем доступы к геолокации: Настройки → Конфиденциальность и безопасность → Службы геолокации → ставим «Никогда» для приложений, которыми уже не пользуетесь. Снизите фоновый трекинг. Юзаем лайфхаки прямо сейчас. ITeach
