Бизнес кейс: Производство кожаных оправ для очков Стартовый капитал: от 600 000 руб. 🕶 Бизнес-идея производства кожаных оправ для очков заключается в использовании отходов кожевенного производства — обрезков искусственной и натуральной кожи, которые остаются после раскройки материала. Из них можно шить модные и стильные оправы для очков. Начальный капитал пойдёт на покупку производственной линии и расходных материалов, а также аренду помещения и выплату зарплаты рабочим. Приобретите оборудование. Например, линию для производства оправ, которая предназначена для использования полуфабрикатного сырья — дроблёного пластика и готовых (смешанных в нужной пропорции) цветовых реактивов для него. Для обслуживания линии потребуется 3–4 работника средней квалификации. 👌 По структуре оправы для очков из кожи получаются гибкими и долговечными. Пижонские оправы пришлись по душе хипстерам, байкерам да и просто модникам.
