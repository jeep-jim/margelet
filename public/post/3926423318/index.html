‼️ ALERTE : LE DOMAINE T.ME DE TELEGRAM SUSPENDU ? Le registre du ".me" / GoDaddy, a placé le domaine t.me (cœur des liens Telegram) en statut serverHold. Conséquence immédiate : tous les liens t.me sont morts dans le monde entier. Ils ne résolvent plus via DNS. Les invitations, canaux et partages web sont inaccessibles. L’application Telegram continue de fonctionner pour les utilisateurs déjà connectés (via son protocole propre), mais tout ce qui passe par les liens courts est bloqué. Le changement date de ce soir (13/07), sans explication officielle de Telegram ou du registre .me !
