По его словам, уже наработан большой международный опыт по созданию таких баз, которые нужны в первую очередь для обеспечения безопасности. «Это в первую очередь требование безопасности, требование сегодняшнего дня, потому что IMEI есть у любого сложного устройства», — сказал Боярский.
