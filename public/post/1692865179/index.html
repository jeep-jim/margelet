#APPLE #iOS 🍎 自留地 Apple 新系统短评（二） 👨🏻‍💻 主编张启：iOS 27 初体验 刚更新完 iOS 27 最大感觉就是几乎没有变化，不像前几代大刀阔斧的改设计语言改控制中心改锁屏界面，这一代几乎没有变化。感知较强的就是强制 app 使用系统键盘，我认为就是叫 iOS 26.7 也没错，所以主要想分享一下这一周来遇到的 bug： ① iMessage 对话框键盘无法弹出，只能退出当前聊天页面再重新进入才能弹出键盘 ② 今早和某位朋友 iMessage 的消息突然消失，仅剩七天前的一条消息 ③ 某些软件键盘会遮挡部分输入框 ④ Telegram 的bug是最严重的，偶尔出现屏幕下半部分的模糊遮挡 ⑤ 截图后当场编辑无法生效，保存之后还是原图状态 🙋🏻‍♂️ 群友 Kingsley Leung：macOS 27 1️⃣ UI 界面和交互 这次 macOS 27 引入了网上呼声很高的 Liquid Glass 无极调整的选项，虽然我个人对 Liquid Glass 还好，不过有比没有好，有得选择才是老板嘛（笑）。 界面的交互也发生了一些改变。Mission Control 的动画终于不是生硬的线性动画了，改成了非线性动画，而且速度快了一些，用起来舒服不少。哦还有，在触控板上三指上滑/下滑进入 Mission Control 或 App Expose 的时候，现在可以往同一个滑动方向来退出了，不像以前必须要反方向才能退出。这确实是方便了，但是就有点不遵从「从哪里来回哪里去」的设计原则了。此外，细节的完善也能看出来团队下了功夫，现在使用中文输入法输入头括号会自动补全尾括号了，我还以为这是 iOS 27 才有的特性，原来这次 macOS 也同步跟进了。 UI 体验可圈可点，但依然有不少设计不算完善。无论是新老软件，UI 还是欠打磨，目前有很多地方的圆角都有不同的曲率，存在不一致的情况。在下载完 New Siri 之后，Application 列表和 Spotlight 的 UI 会变成非常浓重的 Liquid Glass 风格，但总感觉还没完工，看着好奇怪。Spotlight Search 甚至还遇到了一个有趣的小 bug，偶尔出现四个功能图标直接挤占了主要的 panel。希望在接下来几个 Beta 版本能有所改善。 值得一提的是，这次在内屏的状态栏里加了个很实用的新功能：当刘海右侧空间不足以放下所有的状态栏图标的时候，会有一个按键把剩余的状态栏图标给展开到刘海左边了。这也是个被第三方做了好久终于有官方 implementation 的功能了，只不过第三方们的灭顶之灾这就来了，笑。 2️⃣ 稳定性与应用兼容 顺便提一嘴，我用的测试设备是 MacBook Air M3 24GB。实际流畅度其实倒没有网上说的那样那么非常顺畅，还是有很多 bug 给人感觉有些卡，不过可能也是背后在 indexing，还没完成吧。 这次的升级在应用兼容性与系统流畅度上表现得有些挣扎。底层 Liquid Glass 的大改导致了现有应用的兼容性问题，比如 Orion Browser 的 tabs 全部都变得模糊了。系统自带的 Safari 27 在当前 tab 也有比较明显的显示异常，能用，但就是看着难受。不过在游戏方面倒是有个好消息，我试了一下玩 PlayCover 安装的 Arknights: Endfield，是没有问题的。 除此之外，更新之后的系统界面存在明显的性能卡顿。Application 列表就还是很卡，每个图标都是一个个出来的，感觉就还是 lazy loading，不像早期 macOS 15 那会都是提前预先加载好的顺滑感。多屏幕的时候还会触发 Bug，内屏的状态栏图标会被莫名其妙拉伸，等待后续版本修复。 在 macOS 27 中，Apple 继续对 iPhone Mirroring 功能进行了优化，更新完成之后该功能可以正常使用（和部分群友似乎不太一样？可能是 iOS 27 导致的，而不是 macOS 27 导致的吧）。配合搭载 iOS 26 的 iPhone，现在虽然还不能自由调整长宽比例，但是已经可以进行自由等比例缩放了，期待有一天可以在 macOS 上玩到全屏的学マス吧（笑）。 3️⃣ Apple Intelligence 关于 Apple Intelligence，这次我用网上的 command 命令行偷跑启动了 New Siri。第一次启动是需要额外下载新的 assets 的。值得注意的是，New Siri 启动之后，系统里老的 ChatGPT Extension 会被自动关闭，当然你可以重新启动，但就总感觉 Apple 和 OpenAI 现在的关系，你懂的。 至于实际体验，New Siri 用起来已经非常像 ChatGPT 和 Gemini 这类型的成熟应用了，而且它的优势在于深度整合了 Apple 本身的服务（比如可以整合调用 Apple Maps）。虽然如上面说到，目前的 UI 还有很强的“半成品”感，但能够看出 Apple 在系统级智能的深度集成上已经迈出了实质性的一步。 👀 Newlearner365 近期一直在观望大家对于 OS 27 的反馈，也邀请了一些主编和群友进行了体验。总的来讲，大家反馈新系统功能更新较少，没有太多需要展开讲的东西。同时，针对 UI 和流畅度的优化让人十分舒适，这让我也跃跃欲试。总之，目前来看 OS 27 或许是另一个 iOS 12，值得用来养老。最后，令人遗憾的是，Apple Intelligence 在国内还是一张白纸，而我们什么也做不了，只能等待 💬 欢迎各位读者朋友分享你升级后的体验 & 吐槽遇到的 Bug 频道：@NewlearnerChannel
