Вышла Claude Opus 5 Новая модель почти догнала флагманскую Claude Fable 5 по качеству, но стоит в два раза дешевле. При этом цена вообще не изменилась по сравнению с Opus 4.8. Opus 5 лучше справляется со сложным программированием, многошаговыми задачами, исследовательской работой и использованием инструментов. В GitHub Copilot модель уже рекомендуют для долгих агентных сценариев, где важно не просто написать код, а самостоятельно проверить изменения и довести задачу до конца. По внутренним тестам Anthropic, Opus 5 показывает результаты почти на уровне Fable 5 в кодинге, а на некоторых агентных бенчмарках становится новой SOTA моделью при заметно более низкой стоимости выполнения задач. Еще одно нововведение это режим Fast. Он ускоряет генерацию примерно в 2,5 раза для задач, где важнее скорость, чем максимальное качество ответа. Также появилась настройка уровня “усилия”, которая позволяет выбирать баланс между скоростью, стоимостью и качеством рассуждений. Anthropic также заявляет, что Opus 5 стала самой безопасной и наиболее следующей инструкциям моделью в линейке Opus. По внутренним проверкам она реже демонстрирует нежелательное поведение и точнее придерживается заданных правил. Claude Opus 5 уже доступна во всех платных тарифах Claude, через API и в GitHub Copilot.
