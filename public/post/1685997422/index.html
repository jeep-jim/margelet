Традиционные бренды говорили о них как о «технологии будущего» без конкретных дат. Но Volvo Cars нарушила молчание. 🎤 CEO Хокан Самуэльссон: → «С 2019 года каждая новая модель Volvo будет иметь электродвигатель»; → Конец эры автомобилей только с бензином или дизелем; → Три типа силовых установок для всех моделей: мягкий гибрид, плагин-гибрид, чистый электрокар. Амбициозные цели: ✅ Продать 1 млн электрифицированных авто к 2025 году; ✅ 50% продаж - чистые электромобили к 2025; ✅ Полная климатическая нейтральность к 2040. Почему именно Volvo? 🇨🇳 Поддержка Geely: → Китайский владелец уверен, что будущее за EV; → Доступ к батареям и технологиям из Китая; → Volvo стала полигоном для премиальной электрификации Geely. 🚗 Ключевые модели: → 2020: XC40 Recharge - первый массовый BEV; → 2022: C40 Recharge - купе-кроссовер; → 2023: EX90 - флагманский электрический SUV; → 2024: EX30 - компактный хэтчбек. Заявление Volvo стало катализатором для конкурентов: → Jaguar Land Rover (2018): все новые модели электрифицированы с 2020; → Ford (2021): $30 млрд инвестиций, 40% EV к 2030; → GM (2021): только электромобили к 2035; → VW (2021): прекращение разработки новых ДВС после 2026; → Mercedes (2021): Electric Only с 2030.
