Встречайте - АнтиШифровальщик 🙌🏻 Около месяца назад Positive Technologies представили новую версию MaxPatrol Endpoint Security, включая Proof-of-Concept нового модуля, способного восстановить файлы, если атака зашла слишком далеко. ⛔️ АнтиШифровальщик восстановит файлы, поврежденные шифровальщиками или вайперами. Что важно: 🟢 АнтиШифровальщик использует собственный драйвер для мониторинга файловых операций; 🟢 Для хранения снэпшотов используется нативная подсистема Windows - Volume Shadow Copy Service (VSS); 🟢 VSS-снэпшоты охраняются драйвером, шифровальщик не удалит их через vssadmin; 🟢 VSS-снэпшот занимает 10% от размера диска; (вам не понадобится еще один хард на каждый хост😉); 🟢 Прикапываем состояние файлов перед восстановлением на случай ложных срабатываний; 🟢 54 типа шифровальщиков и 19 типов вайперов - всех протестировали, LockBit, WannaCry, Akira, HellCat, Medusa...
