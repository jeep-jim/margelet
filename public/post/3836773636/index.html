⚠️ Теперь передавать любые файлы с телефона на телефон можно без Wi-Fi, Bluetooth и доступа к интернету — на GitHub вышло гениальное приложение Decimen — Отправляемый файл разбивается на сотни мелких фрагментов (пакетов); — Затем для каждого пакета генерируется свой QR-код, который расшифровывает данные и воссоздает их; — QR-коды сменяются так быстро, что «загрузка» достигает скорости в ~128 кб/с; — При этом есть фича для восстановления потерянных пакетов — на случай, если какой-то из сотен QR-кодов считается неправильно. Сохраняем себе и делимся любимыми мемами правильно: github.com/bashalarmistalt/decimen-optical-transfer 🙈 Подписаться на Лепру 🙈
