تو این پست قبلا گفته بودم چطوری یک سری مخاطب مشخص کنید که وقتی زنگ زدن گوشی رو سکوت نباشه ولی برای بقیه باشه اما چطور گوشیمون رو وقتی رو سایلنته و گمش کردیم پیدا کنیم تا حالا شده گوشیتون رو تو خونه گم کنید و چون رو سایلنته، هرچی زنگ می‌زنید پیداش نکنید؟ یا کار واجبی با خانواده و رفیقتون دارید ولی گوشیش سایلنته و جواب نمیده؟ با این ترفند خفن، فقط کافیه یه پیامک مشخص (مثلاً کلمه‌ی zang) رو به گوشیتون بفرستید تا از حالت سایلنت خارج بشه و بتونید باهاش تماس بگیرید آموزش برای گوشی‌های اندرویدی (عمومی) برای این گوشی‌ها به نرم‌افزار MacroDroid نیاز دارید که می‌تونید از پلی‌استور دانلودش کنید. (نسخه رایگانش برای این کار کافیه). نرم‌افزار رو دانلود و نصب کنید. پایین صفحه روی علامت (+) کلیک کنید. در بخش Triggers (ماشه ها)، گزینه SMS Received رو انتخاب کنید و کلمه‌ای که میخواید (مثل zang) رو تنظیم کنید. حالا در بخش Actions (اقدامات)، گزینه Volume Change رو انتخاب کنید و صدای زنگ (Ringer) رو تا آخر زیاد کنید. تیک تایید رو بزنید و دسترسی‌های لازم رو به برنامه بدید. کار تمومه آموزش برای گوشی‌های سامسونگ (بدون نیاز به برنامه) اگر گوشیتون ONE UI 7 به بالا هست: این فایل دانلود کنید و گزینه‌ی Modes and Routines رو انتخاب کنید. در صفحه‌ی باز شده، پایین صفحه Save رو بزنید. به همین راحتی اگر گوشیتون ONE UI 7 به پایین هست (تنظیم دستی): وارد تنظیمات گوشی بشید و گزینه‌ی Modes and Routines رو انتخاب کنید. از پایین صفحه، سربرگ Routines رو بزنید و علامت (+) بالای صفحه رو انتخاب کنید. حالا پایین بخش If رو بزنید، Message received رو سرچ کنید و کلمه‌ی مدنظرتون رو بنویسید. حالا در بخش Then، وارد قسمت Sounds and vibration بشید، گزینه Sound mode and volume رو انتخاب کنید و حالت رو روی Sound (با صدای بلند) قرار بدید و ذخیره کنید. آموزش برای گوشی‌های آیفون (بدون نیاز به برنامه) این قابلیت برای گوشی‌های آیفون از مدل iPhone 15 Pro به بعد ارائه شده. وارد برنامه Shortcuts بشید. سربرگ Automation رو انتخاب کنید. وسط صفحه New Automation رو بزنید. گزینه‌ی Message رو انتخاب کنید. گزینه‌ی Choose رو بزنید و کلمه‌ی مدنظرتون (مثلا zang) رو وارد کنید. تیک Run Immediately رو بزنید و از بالای صفحه Next رو انتخاب کنید. گزینه‌ی Create New Shortcut رو بزنید. سربرگ Controls رو انتخاب کنید و گزینه‌ی Set Silent Mode رو پیدا کنید و از حالت On به Off تغییرش بدید. حالا پایین صفحه روی نوار Search Actions بزنید و دوباره وارد سربرگ Controls بشید. این بار Set Volume رو انتخاب کنید. گزینه‌ی Media رو روی Ringtone قرار بدید و ولوم صدا رو از 50 روی هر عددی که می‌خواید (مثلاً 100) تنظیم کنید. تیک بالای صفحه رو بزنید و تمام. @Farda_Ai
