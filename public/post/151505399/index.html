#Browser #Extension #GitHub #Tools 🔵 OGee：一键预览网页在多平台的链接分享卡片 🔗：Chrome Web Store | GitHub 🌐 在跨平台分享内容时，一个正常显示的链接预览卡片，往往是现代数字生活中被忽略的「体面」。之前我们盘点过 Fix Link Embeds 一类工具，它们试图帮助用户绕开平台的重重限制，生成符合标准的预览卡片。 🧑‍💻 如果说 Fix Link Embeds 属于分享者的「举手之劳」，那么今天介绍的 OGee 则更站在创作者这边，让开发者在发布链接之前，轻松预览当前网页在各平台上的最终呈现样式。 🧩 OGee 是一款 Chrome 扩展。在任意网页点击扩展图标，即可直观预览该页在 Twitter、Facebook、LinkedIn、Slack、Google 及 Telegram 等平台的分享卡片——无需粘贴 URL 跳转三方网站，也不需等待服务器抓取。开发者可使用它快速核对排错，而对设计师而言，那些精美的 OG Image 本身就是不错的参考素材。 ✨ 功能亮点 - 点击工具栏扩展图标，或使用快捷键 Alt + Shift + O 一键呼出 - 多平台并排展示，模拟不同平台的裁图、截断与域名等展示习惯 - 完全本地运行，免注册登录，零数据追踪，不上传任何数据 - 支持一键下载当前网页的 OG 图片，或直接复制图片地址 - 支持深浅色模式切换、平台显隐与拖拽排序等 💡 出于最小化权限，OGee 目前仅在本地读取你当前打开的页面。若平台用爬虫抓取、有缓存，或对爬虫返回不同 HTML，真实分享卡片仍可能与预览有差别。 📍 首发频道｜小红书｜Twitter｜微信公众号 频道：@NewlearnerChannel
