Base基金启动开发者扶持计划，押注RWA、稳定币、AI Agent与链上金融未来 ME AI 消息， Base 生态基金（Base Ecosystem Fund）发布《Request for Builders: Funding the Future of Global Finance》，宣布将为致力于构建下一代全球金融基础设施的创业团队提供早期资金支持和生态资源。其目标是打造安全、可信的全球金融基础设施，让金融系统能够在全天候（24/7）运行，并通过深度流动性支持大规模交易。但基础设施的价值最终取决于其上层应用，因此基金希望寻找能够创造真实应用场景的开发者和创业者。 Base 生态基金将重点支持 Pre-Seed 和 Seed 阶段项目，并提供资本投入以及 Base 团队的技术、生态和业务支持，此次公布的重点投资方向包括： 1. 代币化（Tokenization），Base 正关注现实世界资产（RWA）上链，包括收益型资产、短期营运资金工具、发票融资、贸易融资、收入分成融资，以及 REITs、版权收益、私人信贷基金等长期资产。基金希望支持具备专业资产发行和管理能力的团队。 2. 稳定币与新兴市场金融，Base 看好稳定币在现金主导型市场中的应用，包括连接线下现金网络与稳定币支付体系，以及推动本地货币稳定币发展，为用户提供更低成本支付、储蓄和金融服务。 3. 链上信用与借贷，基金关注无抵押消费信贷、多方信用体系等方向，希望利用 zkTLS、智能合约和稳定币基础设施，建立新的信用评估和贷款分发模式。 4. 预测市场，Base 认为条件资产市场和垂直化预测市场仍具较大潜力，包括政治、文化、保险风险管理、临床试验等领域，通过市场机制提升未来事件的信息发现能力。 5. 传统金融链上化，基金重点关注外汇市场、链上双边协议等机构级金融基础设施，希望利用稳定币、智能合约和链上结算体系重构传统金融市场。 6. AI Agent 商业应用，Base 表示，随着 AI Agent 基础设施快速发展，下一阶段重点将从“构建 Agent”转向让 Agent 真正参与消费交易，包括智能购物、自动结算、预订服务以及基于稳定币和 x402 协议的商业场景。 此外，Base 还关注 SKU 代币化，希望将传统 Web2 商品目录转化为链上可组合资产，使 AI Agent、钱包和交易平台能够直接发现、交易和购买商品。Base 生态基金表示，以上方向代表当前重点关注领域，但最重要的信号仍来自创业者自身对于未来金融体系的判断。（来源：ODAILY） https://www.me.news/news/296248
