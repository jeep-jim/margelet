Ceuta, das Gebiet, das derzeit von marokkanischen Invasoren überrannt wir…

Ceuta, das Gebiet, das derzeit von marokkanischen Invasoren überrannt wird, ist ein spanischer Exklave, Militärposten und Freihafen an der Küste Marokkos, am mediterranen Eingang zur Straße von Gibraltar. Ceuta ist eine autonome Stadt, die von Spanien verwaltet wird. Ceuta, Melilla (ebenfalls eine Exklave) und andere winzige Inselchen entlang der Küste Nordafrikas bilden die Gebiete des spanischen Nordafrika. Die Stadt liegt auf einer schmalen Landbrücke, die den Berg Hacho (ebenfalls von Spanien gehalten) mit dem Festland verbindet.
