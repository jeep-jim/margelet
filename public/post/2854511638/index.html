Бесплатный шрифт, который не сможет читать ИИ ShieldFont сможет прочесть…

Бесплатный шрифт, который не сможет читать ИИ ShieldFont сможет прочесть человек, тогда как искусственный интеллект увидит вместо него бессмысленный набор слов. Дело в том, что большинству ИИ-ботов удобнее работать с исходным HTML-кодом страниц. С помощью алгоритма замены глифов OpenType, примерно четверть слов подменяется. Фича не сработает с ИИ-ботами, которые читают не HTML-код, а распознают знаки на отрисованной веб-странице. Пока работает только с англоязычными текстами; материалы проекта доступны на GitHub.
