MoK решает проблему задержек при обмене данными между GPU - в MoE-сетях этот процесс может занимать более половины времени обучения. Инструмент объединяет маршрутизацию токенов и вычисления в единый низкоуровневый массив для их параллельного выполнения и минимизации простоя оборудования. В тестах на кластере из 512 GB300 общая пропускная способность выросла на 41%, а обработка MoE-слоев ускорилась в 2,37 раза по сравнению с аналогами. По словам Cursor, компания применяет MoK для обучения модели Composer. Инструмент работает исключительно с архитектурой NVIDIA Blackwell и открыт под лицензией Apache 2.0. cursor.com @ai_machinelearning_big_data #news #ai #ml
