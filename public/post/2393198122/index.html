#macOS #iPad #iPhone #APP #GitHub情报 💻 OpenDisplay：Sidecar 与 Duet Display 的开源替代品，把闲置的 iPhone / iPad 变成 Mac 第二显示屏 🔗：GitHub | Web | Releases | Demo 👉 Features - 作为 macOS 的独立第二屏，而不是简单镜像，可以把窗口拖到另一块屏幕 - 支持 USB / Wi-Fi 两种连接方式 - Retina / HiDPI 支持，文字和图标更加细腻 - 支持触摸输入 - 提供低延迟 H.264 视频传输 - 开源、隐私友好，无需同一 Apple ID，绕过设备限制 🖥 用移动设备给 Mac 做副屏这件事，早在十多年前就有人付诸实践了。一群前 Apple 工程团队成员创办了 Duet Display 公司，通过 Lightning 数据线连接 Mac 和移动设备，即可用作 Mac 的镜像 / 扩展屏。后来，Duet 针对 Apple Pencil 进行了优化，也引入了 Wi-Fi 连接方式 💡 同时期，另一个团队坚持他们的「硬件思路」，即通过插上加密狗让 Mac 把它识别成一块真实连接的显示器，这就是 Luna Display。不同于 Duet 的软件虚拟方案，Luna 的硬件方案能够获得更稳定的 GPU 加速、更好的兼容性和更低的延迟，同时价格也不便宜 👾 直到 2019 年，Apple 推出了官方的 Sidecar（随航）功能，支持原生将 iPad 作为 Mac 的第二屏，这给 Duet 和 Luna 都带来了不小的压力。于是转向跨平台（Windows、Android）、Mac-to-Mac、Mac mini 即插即用、订阅制等方向，不断打磨功能细节和体验，但依然逃脱不了逐年被边缘化的趋势 👀 而开源项目 OpenDisplay 的出现，无疑加速了这一进程。它利用了 macOS 的虚拟显示器（Virtual Display）接口，这块屏幕实时编码（H.264 视频流）发送到 iPhone / iPad，移动设备负责解码显示，并把触摸事件传回电脑。它绕开了 Sidecar 需要同一 Apple ID 的限制，虽然功能方面不如商业软件（譬如缺乏 Apple Pencil 支持），但胜在开源免费。许多未来规划的功能详见 路线图 📘 关联阅读： 1️⃣ Deskreen：将局域网设备变为电脑的第二块屏幕 2️⃣ 老 Mac 机型支持 SideCar 的方法 频道：@NewlearnerChannel
