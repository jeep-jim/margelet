#群友分享 普法资讯：2026年8月境外电诈回流人员分级量刑新规解读 针对境外电信诈骗归国涉案人员，司法机关出台分层量刑执行标准，根据嫌疑人在团伙内的岗位、职责划分处罚档位，同时明确量刑从轻、从重法定情节，具体细则如下： 一、按岗位划分量刑标准 1. 犯罪集团首要分子（创始人、实际出资人） 需对团伙全部涉案金额承担刑事责任，涉案金额较大时刑期普遍在十年以上，最高可判处无期徒刑。即便具备自首情节，刑期也很难降至三年以下，缓刑适用空间极小。 2. 团伙骨干人员（组长、主管、财务、培训、行政管理人员） 1. 本人存在业绩记录：刑期多集中在4至8年； 2. 无法查实具体业绩，但在窝点长期任职：刑期一般为3至6年； 该类人员基本以实刑为主，缓刑案例极少。 3. 基层业务员（普通从犯） 1. 可查实个人诈骗金额：结合涉案数额，同时适用从犯减轻处罚条款； 2. 无实际诈骗业绩，但在诈骗窝点工作满30天：量刑基准为3至10年。 若叠加自首、认罪认罚、全额退缴违法所得等多项从轻情节，刑期可降至1至3年，部分地区符合条件可适用缓刑。 4. 纯后勤辅助人员（食堂、维修、保洁，全程不接触诈骗业务） 任职周期短、非法获利金额低，司法实践中不起诉、定罪免刑或者判处缓刑的概率较高。 二、关联罪名处置规则 如果行为人同时触犯诈骗罪与偷越国（边）境罪，司法实践一般择一重罪进行判处，不再叠加数罪并罚。 三、可争取的从轻量刑情节 嫌疑人可主动举证争取全部从宽认定条件： 1. 主动回国自首、如实供述、自愿认罪认罚； 2. 争取认定从犯身份（底层从业人员重点辩护方向）； 3. 全额退还个人工资、提成等全部违法所得； 4. 举证自身属于被诱骗、胁迫出境的胁从人员（认定标准严格）； 5. 入职时间短、获利较低，属于初次犯罪，或具备立功表现。 四、会加重量刑的从严情节 具备以下情形将直接提升量刑档位： 1. 担任管理岗位、骨干职务，或是主动招揽、招募其他人员参与诈骗； 2. 在境外窝点从业时间较长； 3. 专门针对老年人、学生等弱势群体实施诈骗； 4. 拒不认罪、拒绝退缴赃款； 5. 存在犯罪前科，属于累犯。 五、重要普法提醒 1. 没有实际诈骗到手资金并不代表无需担责，在诈骗窝点任职满30天即可适用3至10年基准刑期； 2. 基层从业人员仅需退还自身实际获利，无需承担整个团伙的全部损失； 3. 单一自首情节不足以直接判处缓刑，通常需要多项从轻情节叠加； 4. 所有在境外针对国内实施电信诈骗的人员，回国后均会被依法追责。 📣订阅东南亚TV: @dnytv ⛔投稿澄清爆光: @dnytv01
