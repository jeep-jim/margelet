Reuters: Китай ведёт прямые переговоры с хуситами для обеспечения прохода своих танкеров через Красное море По данным агентства, переговоры начались после того, как хуситы объявили о блокаде саудовских портов и пригрозили атаковать суда, связанные с их обслуживанием. Пекин обратился к руководству хуситов с просьбой гарантировать безопасный проход китайских танкеров через пролив Баб-эль-Мандеб. «Китай был одной из первых стран, которая напрямую связалась с хуситами по вопросу прохода судов через Баб-эль-Мандеб», — сообщили источники Reuters. По информации агентства, Пекин стремится сохранить поставки нефти из саудовских терминалов на Красном море, прежде всего из порта Янбу, чтобы компенсировать сокращение перевозок через Ормузский пролив, который оказался фактически закрыт из-за конфликта вокруг Ирана. Reuters отмечает, что с момента объявления хуситами новых ограничений как минимум четыре танкера с нефтью уже вышли из саудовских портов в направлении Китая и успешно прошли через Баб-эль-Мандеб. @kedmi
