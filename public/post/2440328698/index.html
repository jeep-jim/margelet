При этом, половину рекламного дохода платят юзеру через Stripe Connect. Какие у стартапа метрики, сколько рекламного бюджета они уже прокрутили и сколько денег реально выплатили пользователям - пока неведомо. Что всё равно норм, потому что... ну а почему бы нет, делать ничего не надо. Выплаты делают через Stripe Connect. Главный вопрос: "Что сам Anthropic про это думает?" И вот тут интересно. С одной стороны, у обычного Claude Code (CLI, в терминале) есть официальные настройки, где можно подменить спиннер и строку статуса, это вполне легально. Но версия для VS Code (это которая в Cursor, или где Claude стоит как окошко поверх) работает иначе. Там Kickback приходится вскрывать файл официального расширения Anthropic, находить внутри кода нужный кусок и дописывать туда рекламу. А чтобы эта реклама вообще могла отчитаться о показе - стартапу приходится ослабить встроенную защиту Content Security Policy. То есть, в обычном Клоде они порядочный "квартиросъёмщик", а в VS Code - бесстыжий оккупас. Тем не менее, придумано круто. Люблю такое.
