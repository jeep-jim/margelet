Minecraft впервые за 17 лет повысил рекомендуемые системные требования — теперь игре нужно 16 ГБ ОЗУ. Microsoft обновила рекомендации для Java Edition. Теперь для комфортной игры в 1080p и 60 FPS советуют 16 ГБ оперативной памяти, процессор уровня Intel Core i5-12400 или AMD Ryzen 5 5600, а также видеокарту уровня RTX 2060 или Radeon RX 5600 XT с 6 ГБ видеопамяти. Минимальные требования тоже выросли: теперь потребуется не меньше 8 ГБ ОЗУ вместо прежних 4. Кризис памяти не даст поиграть даже в «Майнкрафт»😒😒😒
