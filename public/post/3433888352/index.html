В Одессе мужчина открыл огонь по сотрудникам ТЦК, его квартиру штурмуют, пишут местные паблики. Мужчина выбежал из дома и начал стрелять из пистолета по сотрудникам Овидиопольского районного ТЦК, которые проводили мобилизацию. Ранения получили четыре человека. У 25-летнего сотрудника ТЦК - огнестрельное ранение спины в области легких, он госпитализирован. Еще трое сотрудников с огнестрельными ранениями самостоятельно обратились за медицинской помощью. По предварительной информации, сейчас силовики пытаются взять штурмом квартиру, где находится стрелявший.
