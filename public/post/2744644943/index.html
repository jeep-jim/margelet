اگر از ویندوز استفاده می‌کنید، اپلیکیشن YogaDNS می‌تواند ابزار کاربردی‌ای…

اگر از ویندوز استفاده می‌کنید، اپلیکیشن YogaDNS می‌تواند ابزار کاربردی‌ای باشد. از جمله قابلیت‌های آن: امکان استفاده از DNS متفاوت برای هر سایت یا بازی؛ یعنی لازم نیست کل ترافیک اینترنت را از DNS ضدتحریم عبور دهید. فقط سرویس‌های موردنیاز را از آن عبور دهید و برای بقیه اینترنت از یک DNS سریع مانند 1.1.1.1 استفاده کنید. برخی بازی‌ها و لانچرها ممکن است از DNS اختصاصی خود استفاده کنند. YogaDNS می‌تواند کمک کند تا درخواست‌های DNS از DNS دلخواه شما عبور کنند. فعال‌سازی DNS امن (DoH، DoT و DNSCrypt) تنها با چند کلیک و افزایش امنیت درخواست‌های DNS. + نکته: YogaDNS فیلترشکن نیست؛ اما در کنار DNSهای ضدتحریم می‌تواند تجربه بهتری هنگام استفاده از برخی سرویس‌های تحریم‌شده فراهم کند و در بعضی شرایط از بروز خطاهای مرتبط با DNS هنگام ورود به بازی‌ها یا سرویس‌ها جلوگیری کند. لینک سایت @Farda_Ai
