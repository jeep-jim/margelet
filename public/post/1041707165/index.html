Япония планирует внедрить ИИ в армию для управления военнными и выбора це…

Япония планирует внедрить ИИ в армию для управления военнными и выбора целей. Правительство страны рассматривает возможность внедрения американских систем искусственного интеллекта в систему командования, пишет Nikkei Asia. По мнению авторов инициативы, акой шаг должен ускорить принятие решений на поле боя и повысить совместимость японских вооруженных сил с армией США. При этом Токио намерен сохранить контроль над ключевыми процессами с помощью отечественного ИИ. Власти планируют завершить разработку стратегии до конца 2026 года в рамках обновления трёх основных документов национальной безопасности. В ближайшие пять лет искусственный интеллект должен стать одним из ключевых элементов модернизации оборонных возможностей страны. Среди рассматриваемых решений — Maven Smart System (MSS) компании Palantir Technologies и платформа Lattice AI от Anduril Industries. Обе системы уже применяются американскими военными. Главной проблемой остаётся безопасность данных: для работы американским ИИ потребуется доступ к секретной информации Сил самообороны Японии. Чтобы снизить риски, Токио планирует использовать отечественную систему-координатор, которая будет управлять зарубежными ИИ и в будущем позволит постепенно заменить их японскими разработками. Одним из основных кандидатов на роль такого координатора считается модель Sakana Fugu, разработанная японской компанией Sakana AI. Представленная в июне система способна распределять задачи между несколькими ИИ-моделями, выбирая наиболее подходящую для каждой конкретной операции.
