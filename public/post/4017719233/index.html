Зумеры в Корее начали носить с собой специальные камни для снятия тревоги Тренд на покупку гладких карманных камней с небольшим углублением буквально взорвал корейский интернет: молодежь использует эту вещь как новый вид антистресса. Для снятия тревоги лучше носить с собой карманные деньги 😅
