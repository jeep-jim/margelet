Власти начали использовать дефицит бензина, чтобы навязать россиянам «Макс». В Забайкалье ввели QR-коды для заправки В Забайкальском крае начали тестировать продажу топлива по QR-кодам, которые можно получить только через мессенджер «Макс». Об этом сообщил губернатор Александр Осипов. Чтобы записаться на заправку без очереди, водителям нужно зарегистрироваться в боте «Топливо 75», выбрать время и вид топлива. Если лимит не исчерпан, система выдаст QR-код. Повторно получить его можно только через шесть дней. Власти обещают, что обычные очереди на АЗС пока сохранятся, а при успешном тестировании систему распространят на другие заправки. @prosleduet_media
