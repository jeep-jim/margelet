Pekerja dan pengunjung sebuah pasar raya di Kolombong, di sini, bergegas…

Pekerja dan pengunjung sebuah pasar raya di Kolombong, di sini, bergegas keluar menyelamatkan diri selepas kebakaran tercetus di bahagian medan selera premis berkenaan, hari ini. Kebakaran dipercayai bermula di bahagian dapur memasak sebuah gerai sebelum api merebak ke sistem pengudaraan (ventilation) bangunan Bataras Hypermarket Kolombong. Bagaimanapun, tindakan sistem sprinkler automatik bangunan membantu mengawal api daripada terus merebak sebelum pasukan bomba menjalankan operasi pemadaman sepenuhnya.
