开发者发布 iOS 27 usbliter8 越狱方案，目前仅支持 iPhone 11 Pro GitHub 开发者 34306 公开了利用 usbliter8 漏洞为 iOS 27 越狱的完整方案，目前仅支持 iPhone 11 Pro。该方案需借助搭载 RP2350 芯片的 Raspberry Pi Pico 2，通过 SecureROM 漏洞将设备置入 PWN DFU 模式，再刷入定制固件并打补丁实现越狱。 项目警告该操作会抹除设备全部数据，并破坏 SEP、密码、WiFi、基带、蓝牙（仅部分可用）及全部 Apple 服务，仅建议在备用机上尝试。该方案在 wh1te4ever 的 usbliter8 项目基础上新增了绕过 USB 限制模式、沙盒执行限制、AMFI 信任缓存检查等内核补丁。 GitHub 🌸 在花频道 · 茶馆水群 · 投稿通道
