🇲🇦 Зулляйдж: почему марокканскую мозаику собирают вручную Зулляйдж — это традиционная марокканская мозаика, которую вручную собирают из небольших глазурованных плиток. Это ремесло зародилось еще в Средние века и до сих пор остается одной из главных визитных карточек Марокко. 🔸 Для изготовления зулляйджа используют специальную глину, которую добывают в районе Феса. Из нее формируют плитки, обжигают, покрывают цветной глазурью и снова отправляют в печь. 🔸 После обжига мастера вручную раскалывают каждую плитку на десятки небольших фрагментов разных форм — звезд, крестов, ромбов, многоугольников. Для этого используют специальный инструмент, похожий на молоток с заточенными концами. 🔸 Затем фрагменты выкладывают лицевой стороной вниз по заранее подготовленному рисунку. После завершения композиции ее закрепляют раствором и только потом переворачивают. Благодаря этому поверхность получается идеально ровной. 🔸 Орнаменты зулляйджа основаны на сложных геометрических узорах.
