📉 В Новосибирской области с 22 июня уменьшили территориальный коэффициент по ОСАГО. Ранее об этом решении объявил Банк России. Корректировка связана с усилением мер по противодействию страховому мошенничеству в регионе. За первые четыре месяца текущего года по обращениям страховых компаний правоохранители возбудили 217 уголовных дел. Новые значения коэффициентов выглядят следующим образом: 🔹 Для Новосибирска — снижение с 3,12 до 2,34 🔹 Для Бердска — с 2,48 до 1,86 🔹 Для Искитима — с 2,32 до 1,74 🔹 Для остальных городов и населённых пунктов региона — с 2 до 1,5 По итогам первых четырёх месяцев 2026 года средняя стоимость полиса ОСАГО для новосибирских водителей составила 10,9 тысячи ₽, а средняя выплата достигла 151,2 тысячи ₽ 🚘
