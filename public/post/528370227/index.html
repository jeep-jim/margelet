MORFIUS X-Rotor одним импульсом минусует сразу 50 дронов. 🇺🇲 В США оборонная компания Lockheed Martin представила многоразовую систему противодействия беспилотникам Morfius X-rotor, которая не запускает ракеты и не тратит боеприпасы на каждый перехват, система показывает, как направленная энергия может изменить противовоздушную оборону будущего. ◾ Воздушная система MORFIUS X-Rotor использует мощное микроволновое излучение, чтобы одновременно выводить из строя десятки беспилотников, а после атаки возвращаться для повторного применения. Сам производитель заявил, что его система способна вывести из строя более 50 вражеских дронов за один вылет, при этом остаётся пригодной для дальнейшего использования. ▫️ В основе системы MORFIUS X-Rotor стоит технология направленного высокомощного микроволнового излучения HPM. Для полного поражения цели система создаёт мощный электромагнитный импульс, который нарушает работу электроники беспилотника. Такой подход позволяет атаковать не единичную цель, а сразу группы целей, это особенно важно в противостоянии против дешёвых дронов, которые противник может запускать массово. ▫️ MORFIUS X-Rotor получил компактную воздушную платформу с винтовой схемой, которая позволяет доставлять микроволновый излучатель ближе к зоне угрозы. ◾ Производитель Lockheed Martin подчёркивает, что MORFIUS X-Rotor может работать совместно с уже существующими средствами управления и не требует создания какой-то отдельной специализированной инфраструктуры для применения. Это позволяет быстро подключить Morfius X-rotor к уже развернутой инфраструктуре поля боя без дополнительных затрат. ▫️ Если традиционные средства ПВО зачастую сталкиваются с проблемой стоимости и наличия боекомплекта, а ракета-перехватчик может стоить значительно дороже небольшого беспилотника, то массовая атака дешёвых беспилотников способна быстро истощить запас боекомплекта. То новая система MORFIUS X-Rotor с ее микроволновым оружием предлагает новый вариант, как один импульс, который поражает сразу несколько целей без расхода каких-либо боеприпасов вообще. ❗Поэтому многоразовость и нулевой ценник залпа превращают Morfius X-rotor в инструмент защиты, который не ударит по бюджету, а в эпоху огромных туч дронов это — самое главное.
