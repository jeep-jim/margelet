Департамент природных ресурсов штата Колорадо начал феминизировать самцов…

Департамент природных ресурсов штата Колорадо начал феминизировать самцов речной форели с помощью корма с эстрогеном, чтобы сократить её численность в пользу местных видов форели В течение последних двух лет на ручье Бобтейл-Крик биологи пытаются восстановить популяцию местной красногорлой форели, устраняя её конкурентов с помощью генной инженерии. Ручьевая форель, завезённая в XIX веке, стала угрозой для выживания местных видов, не обладающих достаточной адаптивностью. Механизм генной технологии заключается в том, что мальков-самцов кормят кормом с добавлением эстрадиола, который феминизирует их и позволяет им производить икру. Когда такие феминизированные самцы скрещиваются с обычными самцами, четверть потомства оказывается самцами с набором хромосом YY. Часть новых YY-самцов затем снова феминизируют с помощью корма, чтобы они могли производить икру.
