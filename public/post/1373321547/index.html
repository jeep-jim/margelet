Microsoft с помощью нейросетей исправила 570 уязвимостей одним обновлением Во вторник компания выпустила традиционное обновление безопасности для Windows, Office и других своих продуктов. Оно оказалось масштабным: закрыто 570 уязвимостей, две из которых относятся к уязвимостям нулевого дня. Это первые результаты использования системы MDASH, которая использует LLM для анализа кода и поиска потенциальных проблем. И если раньше несколько сотен исправлений в одном релизе были чем-то из ряда вон выходящим, то теперь это может стать обыденностью. Есть ли минусы? Есть. Microsoft рекомендует устанавливать обновления в течение трёх дней, потому что хакеры с помощью уже других нейросетей могут найти и использовать уязвимости за считаные часы. Так что, как бы разработчики ни старались, нам с вами придётся обновлять софт чаще обычного. Главное, чтобы быстрые обновления по старой доброй майкрософтовской традиции не ломали то, что уже работает. Автор: Ян Дашевский
