Поддержка расширенной версии Markdown В Beta-версии Telegram для iOS под…

Поддержка расширенной версии Markdown В Beta-версии Telegram для iOS под номером 12.8 замечена поддержка дополнительных элементов Markdown-разметки в сообщениях. Среди поддерживаемых элементов обнаружены: • Математические формулы. • Таблицы. • Блоки с кодом, включая inline-код. • Чек-листы. • Цитаты. Напомним, что появлению расширенной поддержки Markdown в Telegram предшествовало внедрение нативного просмотра файлов с расширением .md через Instant View. Сейчас эта функция находится на стадии тестирования и не поддерживается у большинства пользователей. В скором времени она может появиться и в приложении для Android.
