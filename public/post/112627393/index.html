#互联网观察 ▎美国结束 37.6 万辆特斯拉 Model 3/Y 转向问题调查：召回后问题已解决 美国国家公路交通安全管理局（NHTSA）已结束对约 37.6 万辆特斯拉车辆转向助力问题的调查，涉及车型为 2023 款 Model 3 和 Model Y。 该调查最早始于 2023 年 7 月，原因是部分车主报告车辆出现方向盘无法转动、转向力度明显增加，或车辆提示“转向助力降低”等情况。2024 年 2 月，NHTSA 将调查升级为工程分析，进一步确认问题范围和成因。 根据 NHTSA 召回文件，相关问题来自电子助力转向系统电路板可能出现过压应力，导致车辆在停车后再次起步时失去转向助力。车辆仍可手动转向，但低速状态下需要更大力气，存在增加碰撞风险的可能。 特斯拉随后在美国召回 376,241 辆相关车辆，并通过免费 OTA 软件更新修复问题。该更新用于防止过压击穿和电机驱动组件过度受压。NHTSA 认为召回措施已覆盖相关缺陷，因此关闭工程分析调查。 需要注意的是，这次调查关闭并不等于该车系所有安全争议结束。它只代表 NHTSA 针对此次 Model 3/Y 转向助力缺陷的工程分析告一段落。 频道 @AppDoDo 官推 APPDOTG
