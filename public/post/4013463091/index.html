Вооружённые силы Российской Федерации продолжили наносить удары по портов…

Вооружённые силы Российской Федерации продолжили наносить удары по портовой инфраструктуре и морским судам, задействованным в доставке грузов для ВСУ. В порту Одессы высокоточным оружием воздушного базирования поражён резервуар с горюче-смазочными материалами, предназначенными для обеспечения украинских войск. Удар пришёлся по резервуарному парку нефтеперевалочного комплекса. На объекте возник пожар, зафиксировано сильное задымление. В порту Южный поражены два сухогруза, доставивших грузы военного назначения. Ещё один сухогруз атакован ударными беспилотниками во время перехода по Чёрному морю северо-западнее острова Змеиный. Судно направлялось в порт Одессы с грузом для ВСУ. В Харьковской области реактивный беспилотник «Герань-4» нанёс удар по территории электрической подстанции «Валки» напряжением 110/35/10 кВ.
