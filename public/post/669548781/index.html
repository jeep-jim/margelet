Разработку выездных виз для россиян назвали в МИД РФ «ахинеей». «Классика…

Разработку выездных виз для россиян назвали в МИД РФ «ахинеей». «Классика иноагентства», — заявила РБК представитель ведомства Мария Захарова. Ранее СМИ-иноагенты сообщили, что власти обсуждают возвращение системы разрешений на выезд из страны. Для поездок за границу россиянам может потребоваться выездная виза, а туристические поездки в «недружественные страны» предлагается разрешать только группами и по утверждённым маршрутам. Подобная система существовала в СССР: для зарубежных поездок гражданам требовалось получать разрешение на выезд. Закон о свободном выезде из страны был принят в 1991 году.
