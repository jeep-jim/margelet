🌸🍀 Рослини — природні кондиціонери 🌺 Азалія — поглинає аміак (міститься в засобах для миття посуду та інших мийних засобах). Ідеально підходить для кухні або туалетної кімнати. 🌸 Хризантема — поглинає трихлоретилен (міститься у фарбах і розчинниках). Рекомендується розміщувати в щойно пофарбованих приміщеннях. 🌳 Фікус — поглинає формальдегід (міститься в клеї для шпалер, ізоляційних та пакувальних матеріалах). Підходить для будь-якої кімнати. 🍃 Філодендрон — поглинає пентахлорфенол (речовину, що може міститися у відходах деревообробної промисловості).
