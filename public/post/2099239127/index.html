#Life #Travel #Car 🚗 当一次西南自驾被完整数据化 等到我们分享这次的西南自驾时，直接是这张在线地图了： https://houjoe.me/tesla-southwest-2026/ 自驾结束已经一周多了。这一次在与朋友分享时，有了更直观的数据与地图视角。我们总共开了 35 天，合计 6294 公里，穿过 5 个省，停留了 26 个地方（超过 1 小时的），所有花费累计 19404 元，住宿占比最大，共 7287 元。交通上，给车充电 31 次，花费 1074 元，其中高速费 3385 元。 这一整趟能被这么完整地复盘，靠的是三条并行的记录线。 🤖 Teslamate，精准记录所有行程。 Teslamate 是个开源免费的特斯拉数据记录工具，我把它部署在了家里的 Nas 上，它就在后台默默记录所有行程。它大概有两个用途，一个是把每天开车的路线生成日程，写到我的日历上，因为我们基本不会真的到 Docker 里去看这些「没有意义」的数据，日历是最接近生活的呈现形式了，方便知道昨天几点几分去了什么地方。另一个就是这次，长途自驾之后，可以真的从里程的维度复盘一下，没有比它更精准的了，而且完全零摩擦。 我自己甚至都没有真正进入到它自带的数据看板，只是让 Claude Code 通过 Mac 终端访问了我的 Docker 容器，把符合要求的数据完整导出成 CSV 到本地，大概 122MB。这么大的原始数据肯定没法直接分享，我基于它稀释了精度，做成了更适合分享的网页，部署在博客上，静态页总共只有 1MB。 ✈️ 无人机，值得留恋处的全景留档。 在这张行程地图上，除了停留点，还标了我的天空之眼全景图片拍摄点。全景是我最喜欢的无人机记录形式，如果一个地方值得留恋，我会起飞无人机拍一张 360 度全景，以后哪怕只是在手机上，也可以再置身其中。而这一路，我们拍到了彩虹、古城、抚仙湖、苗寨、大桥，等等等等，因为带 GPS，能直接和 Teslamate 的行程记录合并。 📝 共享记账，记录零零碎碎的花费。 我们是两个人出行，所以就找了个微信小程序「共享记账」，各自记录各自付款的部分，对每一笔花费心里有数，长途旅行才走得细水长流。 频道：@NewlearnerChannel
