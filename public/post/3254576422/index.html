ترفند نجات‌بخش ویندوز که باید بلد باشی ⚪️تا حالا شده تنظیمات ویندوزت قاطی کنه، برنامه‌ها از کار بیفتن یا ویندوز سنگین بشه؟ یا خودت یک چیزی بزنی خراب کنی لازم نیست فوراً ویندوز عوض کنی خود ویندوز دوتا قابلیت داره که مثل "ماشین زمان" عمل می‌کنن System Restore (بازگردانی تنظیمات) این روش فقط تنظیمات و درایورها رو برمی‌گردونه، بدون اینکه فایل‌هات پاک بشن مسیرش: Start → Create a restore point بعد توی پنجره بازشده برو به System Protection درایو C رو انتخاب کن روی Configure بزن و گزینه Turn on system protection رو فعال کن بعدش Create رو بزن و یه اسم براش بنویس (مثلاً Before update) حالا یه "نقطه بازگردانی" ساختی اگه یه روز مشکلی پیش اومد: دوباره برو همون‌جا → System Restore... → و نقطه‌ای که ساختی رو انتخاب کن تا همه‌چی برگرده مثل قبل System Image Backup (پشتیبان‌گیری کامل از ویندوز) این یکی قوی‌تره از کل ویندوز، تنظیمات، برنامه‌ها و فایل‌هات یه کپی کامل می‌گیره مسیرش در ویندوز 10 و 11: Control Panel → System and Security → Backup and Restore (Windows 7) از سمت چپ روی Create a system image بزن محل ذخیره رو انتخاب کن (مثلاً هارد اکسترنال یا درایو D) بعد Next → Start backup رو بزن برای برگردوندن: Settings → System → Recovery → Advanced Startup → Restart now → Troubleshoot → Advanced options → System Imag Recovery ﻿ @Farda_Ai
