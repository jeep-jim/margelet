🏙 Новые правила заправки. Что известно на данный момент? Уже с завтрашнего дня начнет действовать новый порядок заправки бензином в Липецкой области на следующих сетях АЗС: «Роснефть», «Лукойл», «Газпром», «Тебойл». Мы собрали для вас главные правила: 🏙Новая система заправки по четным и нечетным числам номера автомобиля: 11 июля — бензин будет продаваться для номеров с 1, 3, 5, 7, 9. 12 июля — для 0, 2, 4, 6, 8. Далее по дням месяца; 🏙Лимит: не более 30 литров на одну заправку, в том числе можно в канистры; 🏙Исключения: дизельное топливо будет продаваться без ограничений; АЗС других сетей — без данных правил; 🏙Автомобили без номеров: заправка возможна по документам о покупке автомобиля; 🏙Регион: регистрация автомобиля не важна; 🏙Спецтранспорт: заправка в приоритетном порядке, для них будут выделены отдельные АЗС; 🏙На заправках будут дежурить волонтеры для помощи водителям.
