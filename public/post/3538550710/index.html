При российском ударе по Киеву уничтожен один из ключевых гуманитарных скл…

При российском ударе по Киеву уничтожен один из ключевых гуманитарных складов Украинского Красного Креста По данным организации, сгорели 320 тысяч единиц гуманитарной помощи и оборудования на сумму более 79 млн гривен (1,76 млн долларов). На складе находились грузы для экстренного реагирования на обстрелы, пожары, эвакуации и другие чрезвычайные ситуации: генераторы, тепловые насосы, носилки, дефибрилляторы, аппараты УЗИ, мониторы пациента, а также одеяла, постельное белье, гигиенические наборы, брезент и пленка для аварийного закрытия поврежденных окон. Значительная часть помощи была доставлена в Украину через Механизм гражданской защиты ЕС для усиления готовности страны к чрезвычайным ситуациям. В Красном Кресте заявили, что уничтожение склада стало серьезным ударом по гуманитарной инфраструктуре, от которой зависит доставка помощи пострадавшим от войны людям по всей Украине. Также в результате атаки был поврежден грузовик, использовавшийся для перевозки гуманитарных грузов.
