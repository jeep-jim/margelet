⚡️В Ростовской области задержали жителя Краснодара за незаконную перевозку топлива для перепродажи по завышенным ценам в ЛНР и ДНР. Мужчина перевез 1,6 тонны бензина в грузовом фургоне Ford Transit, не оборудованном для перевозки опасных грузов. По его словам, на протяжении недели, по согласованию с операторами АЗС, он обходил системные ограничения, покупая топливо в Горячем Ключе и Краснодаре. Топливо отпускали в металлические бочки объемом 200 л, не соответствующие требованиям ГОСТ по пожарной безопасности.
