🔒 Новая защита KMS не затронет обычную активацию Windows 11 Microsoft усиливает защиту KMS-серверов, через которые компании централизованно активируют устройства с корпоративными лицензиями. Новые проверки с использованием TPM относятся к узлам активации, а не к домашним компьютерам. Механизм должен привязывать KMS-хост к конкретному оборудованию и проверять целостность платформы. Это усложнит использование поддельных или клонированных серверов внутри корпоративных сетей. Активация Windows 11 через цифровую лицензию, OEM-ключ или обычный розничный ключ не меняется. Новые требования могут затронуть только организации и сторонние схемы, которые действительно используют KMS-серверы. #Micrоsоft
