Ритейл-медиа делают ещё один шаг к прозрачности: Яндекс UrbanAds открыл публичный API для рекламодателей. Через него можно автоматически получать статистику кампаний — буст показов, буст продаж, продвижение в полках, охватные форматы — и синхронизировать её с системами сквозной аналитики. То есть анализировать вместе с другими каналами и площадками в одном окне, без ручных выгрузок. Для рынка это показательный тренд: площадки ритейл-медиа движутся к тому, чтобы данные и аналитика были простыми и понятными для рекламодателя. API также поддерживает работу с отзывами через собственный интерфейс рекламодателя. Настройка — в личном кабинете, раздел «API-интеграции».
