💰 AMD купила софт против дорогой оперативной памяти AMD приобрела MEXT - стартап с технологией Predictive Memory Engine. Она не превращает NAND в настоящую ОЗУ, а заранее переносит нужные данные из флеш-памяти в DRAM, чтобы приложения видели больше доступной памяти без резкого падения скорости. Решение рассчитано на ЦОД, ИИ, аналитику и тяжёлые серверные нагрузки. Для обычных ПК, игр и браузера это не замена оперативке: там слишком непредсказуемые сценарии, а задержки NAND всё равно никуда не исчезают. Для AMD это способ снизить зависимость датацентров от дорогой DRAM и HBM.
