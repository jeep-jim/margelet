Bottega Veneta выпустили линейку аксессуаров из мицелия — корневой системы грибов. В нее вошли картхолдеры, обложки для паспорта, брелки для ключей и два вида кошельков. Все изделия выполнены из инновационного материала Ephea, разработанного итальянским стартапом Sqim. Запуск этой лимитированной коллекции — важный шаг для группы Kering, которой принадлежит Bottega Veneta.
