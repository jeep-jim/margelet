🔍 Создана первая 3D-карта сосудов мозга, снятая ультразвуком через целый череп Лаборатория Aleph Neuro показала детальную 3D-карту сосудов живого человеческого мозга — снятую снаружи, без единого разреза. По словам команды, это — одно из самых полных изображений такого рода. За 4 минуты удалось увидеть крупные сосуды, поверхностные артерии и тонкие артериолы. Человеку вводят стандартный для УЗИ контраст с микропузырьками, алгоритм отслеживает их движение по сосудам, и миллионы точек складываются в объемную карту кровотока. По данным Aleph, объемное разрешение метода примерно в 100 раз выше, чем у КТ. 💡 Это потенциальный путь к нейроинтерфейсу без вживления электродов. Aleph собирается создать на основе технологии компактный чип для «телепатического будущего». Когда участок мозга активируется, к нему поступает больше крови. Поэтому по изменениям кровотока можно косвенно судить о работе мозга. ⚙️ Первым технологию испытал на себе один из создателей Aleph Лев Чижов. Еще школьником петербургского лицея №239 он программировал на Python, интересовался блокчейном и нейросетями. Теперь он работает над тем, чтобы превратить ультразвук в основу нового нейроинтерфейса. Но пока это только исследовательская демонстрация, результат еще не прошел независимое рецензирование. При этом команда открыла код обработки и выложила около 98 ГБ данных, по которым можно воспроизвести процесс построения изображения. 👋 Подпишитесь на Hi, AI!
