Электронная коммерция через маркетплейсы Для работы с маркетплейсами не нужен большой штат сотрудников, собственный офис, склад и курьеры. Все эти этапы можно делегировать площадке. На старте можно обрабатывать каждый заказ своими силами. Например, хранить товары у себя дома и доставлять их самостоятельно, а маркетплейс использовать как площадку для продвижения. Такой формат работы тоже не запрещён. Чтобы начать зарабатывать, определите, какой товар будете продавать. Оценить его потенциал можно с помощью сервиса «Яндекс Вордстат». Для этого нужно посмотреть, сколько раз в месяц ваш продукт ищут в связке со словом «купить». Дальше нужно зарегистрироваться в налоговой в качестве ИП, ООО или самозанятого, а затем создать аккаунт продавца и заключить договор с маркетплейсом.
