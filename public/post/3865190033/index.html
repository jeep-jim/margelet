چطور لوکیشن فیک بفرستیم؟ گاهی اوقات برای حفظ حریم خصوصی یا تست بعضی اپلیکیشن‌ها، ممکنه بخواید لوکیشن واقعی‌تون رو ارسال نکنید. توی این آموزش یاد می‌گیرید چطور با چند مرحله ساده، موقعیت مکانی گوشی اندرویدی‌تون رو تغییر بدید. مراحل انجام کار (اندروید): ابتدا برنامه GPS Emulator را از گوگل پلی دانلود و نصب کنید. وارد Settings شوید و بخش Developer Options (گزینه‌های توسعه‌دهنده) را فعال کنید. در بخش Developer Options، گزینه Select mock location app را انتخاب کرده و برنامه GPS Emulator را به‌عنوان برنامه پیش‌فرض تعیین کنید. ﻿حالا وارد برنامه بشین، موقعیت دلخواه خود را روی نقشه انتخاب کنید و دکمه سبز پایین صفحه را بزنید تا لوکیشن فعال شود.حالا میتونید در تلگرام، واتساپ یا سایر برنامه‌هایی که از موقعیت مکانی گوشی استفاده می‌کنند، همان لوکیشن انتخاب‌شده را ارسال کنید. + این روش روی برخی اپلیکیشن‌ها مانند برنامه‌های بانکی، تاکسی‌های اینترنتی یا سرویس‌هایی که قابلیت تشخیص Mock Location دارند، ممکن است کار نکند. + از این قابلیت فقط برای حفظ حریم خصوصی، تست اپلیکیشن‌ها یا سایر استفاده‌های مجاز استفاده کنید. @Farda_Ai
