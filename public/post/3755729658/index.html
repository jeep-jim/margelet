Россиянам хотят отключать незаконно ввезенные телефоны — для этого создае…

Россиянам хотят отключать незаконно ввезенные телефоны — для этого создается база идентификаторов устройств (IMEI), следует из нового проекта постановления правительства. Операторы и сейчас видят IMEI абонентов, но по проекту должны будут передавать в базу каждый факт активации сим-карты в телефоне. Базу хотят использовать против мошенничества, а также для блокировки украденных, потерянных и незаконно ввезенных устройств.
