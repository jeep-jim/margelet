KI von OpenAI hackt KI-Firma Ein außergewöhnlicher Zwischenfall beim Testlauf neuer KI-Modelle des ChatGPT-Entwicklers OpenAI demonstriert das Risiko potenzieller KI-Cyberattacken. Die Software drang eigenständig in Computersysteme einer anderen KI-Firma ein und verhielt sich dabei wie ein Hacker. Das teilte OpenAI in einem Blogeintrag mit. Die betroffene Firma Hugging Face, eine Plattform für KI-Anwendungen, berichtete bereits vergangene Woche von einem Cyberangriff. Nun stellte sich heraus, dass dieser auf einen internen Versuch bei OpenAI zurückging, den die Software ungeplant deutlich zu weit trieb. Abonniert @satellit_de!
