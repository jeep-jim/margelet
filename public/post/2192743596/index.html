✴️ ChatGPT научился говорить как человек. OpenAI представила GPT-Live для голосового режима. Теперь разговор с нейронкой должен идти свободнее и больше походить на живое общение. Модель уже выкатывают на iOS, Android и в вебе. Для Go, Plus и Pro основной станет GPT-Live-1, а бесплатным пользователям дадут GPT-Live-1 mini. API обещают позже. • Источник @aiaiai
