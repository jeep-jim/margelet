ВС РФ продолжают удары по портам Украины. По данным Минобороны, ракетами…

ВС РФ продолжают удары по портам Украины. По данным Минобороны, ракетами "Оникс", крылатыми ракетами и барражирующими боеприпасами поражены объекты в порту "Одесса". Среди целей - цех сборки беспилотников дальнего действия на территории госпредприятия "Морской торговый порт "Одесса". Киев использует гражданскую портовую инфраструктуру для военных целей, превращая торговые объекты в легитимные военные цели. Применение "Ониксов" - противокорабельных ракет с дальностью до 800 км - указывает на работу по приоритетным объектам. Противник планомерно лишается возможности использовать порты для снабжения, сборки БПЛА и переброски грузов военного назначения. Главное: порты Украины давно перестали быть гражданскими объектами.
