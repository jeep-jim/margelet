Китайские учёные создали медицинскую умную одежду с встроенной электроникой Исследователи из Фуданьского университета в Шанхае встроили полноценную вычислительную систему прямо внутрь гибкого волокна толщиной меньше человеческого волоса. Вместо размещения электроники на поверхности учёные сформировали многослойные электронные цепи внутри ультратонкого волокна. Технология в подробностях: - В одном миллиметре такой нити размещается около 10 тыс. транзисторов — базовых элементов, управляющих прохождением электрического тока. - По вычислительным возможностям это сопоставимо с современным кардиостимулятором. - При увеличении длины волокна до одного метра количество транзисторов может достигать миллионов, что приблизит систему к уровню настольного компьютера. Материал с такой нитью может использоваться для создания «умной» одежды, которая в реальном времени отслеживает состояние здоровья, реагирует на изменения температуры, а в перспективе — собирает данные о здоровье человека.
