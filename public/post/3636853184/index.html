Яндекс Пэй расширил возможности чекаута на базе Yandex Commerce Protocol…

Яндекс Пэй расширил возможности чекаута на базе Yandex Commerce Protocol для интернет-магазинов. Решение можно подключить через готовые модули для 1С-Битрикс и WordPress или по API практически к любому сайту. Чекаут автоматически подставляет данные покупателя и дает возможность подключить доставки и разные способы оплат. Это ускоряет оформление заказа, за счёт чего конверсия в покупку может вырасти примерно вдвое. В личном кабинете также можно без дополнительной разработки подключить программы лояльности на базе RetailCRM и Mindbox и настроить промокоды. Для новых партнёров действуют сниженные тарифы на приём платежей и возможность утроить рекламный бюджет в Директе.
