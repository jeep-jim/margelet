Покупателей хостинга могут обязать регистрироваться через «Госуслуги» Мин…

Покупателей хостинга могут обязать регистрироваться через «Госуслуги» Минцифры обсуждает с хостинг-провайдерами возможное введение обязательной идентификации физлиц через «Госуслуги», пишет «Коммерсант». Если инициативу одобрят, за каждым выделенным IP-адресом может быть закреплен конкретный пользователь с подтвержденной учетной записью, тогда как сейчас у пользователей хостинга есть несколько способов авторизации, в том числе по электронной почте или через оплату картой российского банка. Для владельцев доменов .ru, .рф и .su похожее требование уже действует, напоминает издание. Ранее Минцифры уже предлагало сделать «Госуслуги» единственным вариантом идентификации, но после обсуждения с рынком расширило список допустимых способов. А сейчас ведомство, вероятно, возвращается к идее обязательной привязки пользователя к аккаунту на «Госуслугах», «чтобы за каждым выделенным IP-адресом стоял конкретный пользователь с подтвержденной учетной записью».
