Одобрив кредит, несмотря на то что Киев не обложил налогом иностранные посылки, МВФ вместе с властями Украины разработал дорожную карту для повышения тарифов Международный валютный фонд заявил, что действующая система тарифов для населения и связанные с ней специальные обязательства ухудшили финансовое положение государственных энергетических компаний и ограничили их возможности для инвестиций и ремонта инфраструктуры. «В энергетическом секторе акцент смещается на реформы для подготовки к либерализации рынка. Текущая система коммунальных тарифов для населения и связанные с ней специальные обязательства по предоставлению услуг ослабили финансовое положение государственных энергетических компаний, ограничив ресурсы для критически важных инвестиций и ремонтов. Для исправления ситуации власти при технической поддержке МВФ готовят дорожную карту по поэтапной либерализации энергетического рынка, предусматривающую механизмы социальной защиты для уязвимых домохозяйств. После того как такие механизмы будут готовы и на основе этой дорожной карты, тарифы для населения должны постепенно корректироваться, чтобы решить финансовые проблемы сектора и создать лучшие условия для привлечения инвестиций. Повышение прозрачности, добросовестности и независимости энергетического регулятора (НКРЭКУ) также будет способствовать долгосрочной устойчивости сектора», – говорится в заявлении Международного валютного фонда. Среди обязательств Украины по программе МВФ – отмена льготы по НДС для международных посылок, меры по борьбе с уклонением от уплаты налогов через трансфертное ценообразование, а также реформирование упрощённой системы налогообложения.
