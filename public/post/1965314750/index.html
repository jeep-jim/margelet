WhatsApp* добавила новые функции для групповых звонков WhatsApp анонсировала ряд улучшений для групповых звонков, включая возможность совершать аудио- и видеовызовы прямо из браузера через WhatsApp Web. Новая функция Call Transfer позволяет переводить активный групповой звонок между устройствами, не прерывая разговор. Также стала доступна комната ожидания для звонков по ссылке — она даёт возможность организаторам вручную одобрять доступ участников. Список нововведений пополнили технология QuickHD для мгновенного доступа к видео высокого качества и система подавления фонового шума для чёткости речи. В компании уточнили, что обновления внедряются постепенно и скоро станут доступны всем. *WhatsApp — продукт компании Meta, признанной экстремистской организацией в России.
