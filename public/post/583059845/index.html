Шаг 2️⃣указать дату, например «Начало этого дня». Шаг 3️⃣при помощи кнопки «Настройки/ Вид «Расширенный», закладка «Поля и сортировки» в списке «Поля» оставить флажки у нужных для отображения полей. Шаг 4️⃣ на закладке «Фильтры» установить нужные отборы, например, по организации, подразделению, или добавить свой. Шаг 5️⃣ выполнить формирование отчета по одноименной кнопке.
