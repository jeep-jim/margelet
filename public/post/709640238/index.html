Две задачи в одной модели: Яндекс начал создавать единую модель Alice AI…

Две задачи в одной модели: Яндекс начал создавать единую модель Alice AI ART 2.0 для генерации и редактирования изображений 😨 Раньше генерация по тексту и редактирование по инструкции работали на двух отдельных стеках. Теперь это unified-модель, поэтому улучшения можно внедрять сразу в обе задачи и без дублирования разработки. Знания из t2i (текст → картинка) переносятся в i2i (картинка + инструкция → картинка): например, модель может добавить хохлому или самовар без отдельного сбора специализированных данных для редактирования. Отдельный модуль расширяет промпт ещё до диффузионного генератора. Это повысило точность следования инструкциям при редактировании на величину до 12%. Две системы постепенно становятся одной 🤨
