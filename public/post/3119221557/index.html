🧠 В Бурятии начали выпускать препарат для диагностики опухолей мозга Центр ядерной медицины сделал важный шаг — там запустили собственное производство радиофармпрепарата для раннего выявления опухолей головного мозга. Теперь высокоточное ПЭТ/КТ-исследование можно пройти бесплатно по полису ОМС. Раньше пациентам за такой диагностикой приходилось ехать в другие регионы. Глава Бурятии Алексей Цыденов отметил, что сегодня центр помогает не только жителям республики, но и пациентам из соседних регионов и Монголии. По словам специалистов, запуск собственного производства делает Центр ядерной медицины одним из передовых учреждений в этой сфере.
