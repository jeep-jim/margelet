👆 Стоимость автоперевозок из Китая выросла на четверть за месяц Тарифы на автомобильные перевозки по маршрутам из Китая продолжают расти. По данным участников рынка, за последний месяц стоимость доставки увеличилась на 20–25%, а ключевым фактором стал продолжающийся топливный кризис. По информации СМИ, ежедневно к стоимости рейса добавляется 10–20 тыс. рублей. В результате цена перевозки по маршруту Шанхай — Москва с апреля выросла с 730–750 тыс. рублей до 1,05–1,1 млн рублей. Одновременно сохраняется высокий спрос на автомобильную доставку из КНР: с апреля объём заявок, по оценкам участников рынка, увеличился до 50%. Для импортёров это означает дальнейший рост логистических издержек и необходимость учитывать увеличение транспортной составляющей при планировании поставок и расчёте себестоимости товаров.
