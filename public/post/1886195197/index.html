Вау: Авито запустил сервис для поиска животных при помощи ИИ — «ХвостРадар». Механизм простой: пропавшего питомца можно найти, загрузив фото, а технологии компьютерного зрения сопоставляют его с объявлениями о найденных животных, учитывая локацию. Если система находит совпадение, владельцу объявления предлагают связаться через чат с человеком, который разместил объявление о найденном животном. В будущем в сервисе появятся подписка на объявления, поиск хозяина по фото и автоматический поиск. «ХвостРадар» — собственная разработка Авито, созданная совместно с волонтерами, которые каждый день помогают искать пропавших животных. Самый полезный сервис 🎁🎁
