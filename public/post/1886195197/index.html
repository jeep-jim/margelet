Вау: Авито запустил сервис для поиска животных при помощи ИИ — «ХвостРадар». В будущем в сервисе появятся подписка на объявления, поиск хозяина по фото и автоматический поиск. «ХвостРадар» — собственная разработка Авито, созданная совместно с волонтерами, которые каждый день помогают искать пропавших животных. Самый полезный сервис 🎁🎁
