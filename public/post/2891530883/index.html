Разбираем видеоархив: разраб создал Edit Mind — опенсорс инструмент с ИИ, который помогает искать нужные кадры. 😨 По сути, он превращает видео в поисковую базу знаний: просто загружаете ролики, и у каждой сцены появляется текстовое описание. Разраб так прогнал свой архив из 628 GoPro-роликов прямо на MacBook M1 Max (правда, процесс индексации не самый быстрый). GitHub для тех, кто всегда носит с собой видеокамеру, здесь 📹
