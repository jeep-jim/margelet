В Китае создали прототип сверхбыстрой памяти для квантовых компьютеров, ч…

В Китае создали прототип сверхбыстрой памяти для квантовых компьютеров, что может открыть путь к обработке сверхбольших массивов данных, сообщает South China Morning Post. По словам одного из авторов исследования, учёным удалось создать прототип QRAM, способный работать с 4-битными и 8-битными данными на сверхпроводящем квантовом чипе. Квантовые компьютеры теоретически способны решать сложные задачи на скорости, недостижимой для обычных компьютеров, но для этого им нужен эффективный доступ к классическим данным.
