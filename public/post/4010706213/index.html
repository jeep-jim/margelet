تبدیل مودم قدیمی به تقویت‌کننده وای‌فای اگه خونه یا محل کارت بزرگه و وای‌فای ته سالن زورش نمی‌رسه، لازم نیست دنبال مودم جدید یا تقویت‌کننده گرون‌قیمت بگردی مودم قدیمی‌ت هنوز می‌تونه یه کار درست و حسابی انجام بده با یه تنظیم ساده، می‌تونی اون رو تبدیل کنی به تکرارکننده (Repeater) یا WDS Bridge تا امواج مودم اصلی رو بگیره و دوباره پخش کنه مراحل کلی راه‌اندازی: وارد تنظیمات مودم قدیمی شو (معمولاً با آدرس 192.168.1.1) به بخش Wireless Settings یا WDS / Repeater Mode برو قابلیت Enable WDS یا Repeater Mode رو فعال کن وای‌فای مودم اصلی رو اسکن کن و انتخابش کن رمز وای‌فای اصلی رو وارد کن و ذخیره کن ـ IP مودم قدیمی رو از محدوده‌ی مودم اصلی تنظیم کن (مثلاً اگه مودم اصلی 192.168.1.1 هست، بذار این یکی 192.168.1.2) ـDHCP مودم قدیمی رو خاموش کن تا با مودم اصلی تداخل نداشته باشه بعد از ری‌استارت، مودم قدیمی مثل یه آنتن تقویت‌کننده وای‌فای عمل می‌کنه و محدوده پوشش اینترنتت چند برابر میشه نکته: اگه مودم خیلی قدیمیه و گزینه WDS نداره، می‌تونی با کابل LAN به مودم اصلی وصلش کنی و ازش به‌عنوان Access Point استفاده کنی. @Farda_Ai
