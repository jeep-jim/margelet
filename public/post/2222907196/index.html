Какие основные моменты нужно учитываться при досмотре авто? Прежде чем осуществить досмотр автомобиля, инспектор должен предъявить документ, подтверждающий необходимость проведения досмотра, например, ориентировку. Затем он должен пригласить двух независимых свидетелей для присутствия при досмотре багажника. Затем инспектор должен разъяснить всем приглашенным понятым их права и только после этого начать досмотр. Если понятые отсутствуют, должна быть проведена видеозапись процесса. Водителю разрешается снимать на видео действия инспектора.
