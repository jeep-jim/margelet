Администрация Владивостока может прибегнуть к помощи посредников для выпо…

Администрация Владивостока может прибегнуть к помощи посредников для выполнения плана по набору контрактников для СВО, следует из постановления главы города от 6 июля. В июне для вновь заключающих контракт граждан в столице ДФО ввели единовременные выплаты из городского бюджета. Их сумма составит от 400 тысяч до 1,6 млн рублей. Привлечение посредников для "оказания содействия по привлечению граждан к прохождению военной службы по контракту" широко распространено во многих регионах – пару месяцев назад в одном из федеральных изданий вышло интервью с одним из рекрутеров. По его словам, сумма "вознаграждения" за каждого добровольца стартует от 25 тысяч рублей.
