🔐 Claude научился логиниться за вас! Поручить ИИ забронировать поездку звучит удобно ровно до момента, когда всплывает окно логина. Дальше человек всё равно лезет в браузер руками. 1Password предлагает выход: браузерная интеграция с Claude, которая даёт агенту довести многошаговую задачу до конца, и при этом не показывает ему ни одного вашего пароля. Устроено это через то, что компания зовёт zero-exposure security framework. Нужные учётки подставляются под конкретную задачу по защищённому каналу, в который Claude заглянуть не может. Разрешение пользоваться данными агент получает — сами данные нет. Одноразовый код MFA, кстати, тоже остаётся невидимым. Доступ выдают не оптом, а по задачам, и каждый запрос подтверждается одним биометрическим касанием. Пауза в работе всё равно есть — но она проще, чем отбирать у агента браузер и логиниться самому. Подстраховка есть и на выходе: после каждого автозаполнения 1Password сканирует страницу, проверяя, не торчит ли чего наружу в отправленных формах, и только тогда возвращает управление. Что нужно для запуска: Mac, десктопное приложение 1Password с браузерными расширениями плюс десктоп Claude со своими расширениями. И оговорка на всякий случай. В сейфах 1Password лежат далеко не только пароли: там passkeys, коды 2FA, API-токены, адреса, финансовые данные. К чему конкретно дотянется Claude, компания не расшифровывает — но пока речь, похоже, только про логины. Платёжные карты и документы обещают подключить позже.
