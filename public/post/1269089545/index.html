Grok 4.5 теперь доступен всем пользователям xAI завершила глобальный запуск Grok 4.5. Если раньше модель появлялась постепенно и была доступна только части пользователей, то теперь она стала основной моделью практически во всей экосистеме Grok. Это самая мощная модель компании для кода, агентных задач и интеллектуальной работы. Она умеет писать и исправлять код, создавать приложения, работать с документами Word, презентациями PowerPoint и таблицами Excel. По данным xAI, Grok 4.5 набирает 62.0% на DeepSWE 1.0, 83.3% на Terminal Bench 2.1 и 64.7% на SWE Bench Pro. Скорость генерации достигает 80 токенов в секунду, а при решении реальных задач модель использует примерно в два раза меньше токенов, чем сопоставимые решения. Контекстное окно 500 тысяч токенов. Модель поддерживает function calling, веб-поиск, выполнение кода и работу с изображениями. Стоимость API составляет $2 за миллион входных токенов и $6 за миллион выходных. Теперь Grok 4.5 доступен по умолчанию в Grok и Grok Build, работает в Cursor на всех тарифах, а также доступен через API и популярные AI-шлюзы для разработчиков. dailyprompts.ru
