CSS ::checkmark обещает убрать лишний JavaScript из кастомных дропдаунов Псевдоэлемент ::checkmark из CSS Form Control Styling Module Level 1 позволяет стилизовать галочку выбранного пункта в нативном &lt;select&gt; без кастомной разметки и скриптов. Вместо div-обёртки, стрелочки и ручной навигации с клавиатуры вы задаёте appearance: base-select и переопределяете content у ::checkmark. Ловушка в двух ограничениях: на момент статьи он не работает в Safari и Firefox, а в остальных браузерах поддерживается только для &lt;option&gt; внутри &lt;select&gt; — чекбоксы и радиокнопки пока недоступны. Поэтому кастомные контролы пока остаются нужны. Подробности в разборе Сунканми Фафоворы.
