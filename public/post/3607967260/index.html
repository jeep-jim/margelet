Водородные электродвигатели для самолетов: проблемы и перспективы ⚡️ «Авиация на водороде» – звучит как научная фантастика. А между тем разработка уже стартовала. Станет ли водород топливом будущего для авиации или у него есть более практичные конкуренты – разбираемся в рубрике #технокомменты СМИ сообщают 🔈 Анонсировано создание первого водородного электродвигателя для самолетов. И это лишь часть задачи. Для появления водородных самолетов потребуется развитие всей системы вокруг них: от производства и хранения топлива до новых стандартов безопасности и сертификации. 🗣️🗣️🗣️🗣️🗣️ Своим мнением с нами поделился заместитель начальника отделения «Силовые установки» #КБ_МС «Яковлева» Максим Ильин: ➡️ Тема создания полностью электрической силовой установки на водородных топливных элементах является достаточно интересной с точки зрения ее технической составляющей 🧐 ➡️ Но, существует ряд вопросов по разработке и эксплуатации самолетов с такими силовыми установками, которые на данный момент времени не решены: 🔹 Объем самолетных баков для двигателей, работающих на водороде, превышает приблизительно в 4 раза баки для двигателей, работающих на авиационном топливе. Разместить такие баки в крыле классической конструкции невозможно. Размещение баков в фюзеляже приводит к уменьшению количества пассажиров и к вопросам по аэродинамическим характеристикам самолета 🤔 🔹 Водород крайне опасен с точки зрения взрывобезопасности и воспламеняемости. Потребуется разработка новых норм для сертификации самолетов с силовой установкой на водородных топливных элементах. Создание конструкции, удовлетворяющей таким нормам, может значительно увеличить стоимость разработки самолета. Такие же нормы безопасности необходимо разработать для авиакомпаний; 🔹 Существующая инфраструктура эксплуатации гражданских самолетов разработана для самолетов с двигателями, работающими на авиационном топливе ⛽️ Создание новой инфраструктуры может стать достаточно сложно решаемой задачей. Хранение и перевозка газа дороже, чем аналогичные процессы для топлива. ➡️ Для улучшения экологических характеристик гражданских самолетов существуют решения, которые не связаны с таким количеством вопросов. Например, применение синтетического авиатоплива (SAF – Sustainable Aviation Fuel). При работе двигателей на этом топливе выбросы могут быть снижены до 80% по сравнению с авиационным керосином 📉 Для реализации такого подхода необходимо проведение испытаний компонентов топливных систем двигателя и самолета при минимальном уровне доработок.
