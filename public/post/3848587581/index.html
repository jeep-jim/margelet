Билайн запускает линейку улучшайзеров — новых пакетных решений, которые расширяют возможности тарифа без его полной смены Первым предложением стал улучшайзер «план б.», предназначенный для продвинутой аудитории. Сейчас улучшайзер «план б.» доступен для подключения на подписке bee (би), в дальнейшем Билайн планирует расширять доступность этого формата. Подключить улучшайзер можно будет и к архивным тарифам. Первый месяц - бесплатно, далее - 250 рублей в месяц. Улучшайзер «план б.» подключается как единый пакет и включает: — обмен ГБ на цифровое золото с последующей конвертацией в бонусные рубли для оплаты связи; — дополнительные 1000 ИИ-токенов для доступа к топовым нейросетям без ВПН для решения ежедневных задач; — доступ к библиотеке промтов, чтобы взаимодействие с нейросетями было эффективнее; — игровые механики и систему достижений с бонусами для оплаты связи; — 1 ТБ в Облаке Билайн для хранения фото, видео. Новая линейка отражает стратегию Билайна по развитию более гибкой тарифной модели, чтобы клиент мог дополнять его наборами функций в зависимости от своих задач.
