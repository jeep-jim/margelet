Москва возглавила список самых недоступных городов Европы для покупки жил…

Москва возглавила список самых недоступных городов Европы для покупки жилья. По данным Numbeo, жителю Москвы нужно копить на квартиру больше 22 лет, откладывая всю зарплату. Это худший результат в Европе. Если брать ипотеку, платёж по кредиту съедал бы 453% дохода семьи, то есть в 4,5 раза больше, чем вся зарплата. В десятку самых недоступных городов попал и Нижний Новгород. Там на квартиру нужно почти 18 годовых зарплат, а платёж по ипотеке составил бы 365% дохода семьи. Для сравнения: в Лондоне и Париже показатели заметно ниже, хотя жильё там тоже недешёвое.
