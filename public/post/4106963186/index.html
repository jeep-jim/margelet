A new update Sl8 has already passed review and will be available on the App Store and Google Play very soon. In this version, we have added new features for content creators, expanded the app's functionality, and introduced a number of changes that will make it more stable and user-friendly. 📊 Detailed Statistics for Content Creators The app now features a new Creator Statistics page, where creators can analyze their results, audience activity, and earned revenue in greater detail. The page will include: • interactive charts displaying revenue dynamics; • separate income breakdowns for paid posts, post tips, chat tips, and subscriptions; • information about top-performing content; • a list of top contributing fans; • a history of recent purchases, active subscriptions, and sent tips. With detailed analytics, creators will be able to better understand their audience's activity, see which content generates the most interest, and more accurately evaluate the results of their work. 🛠 Bug Fixes and App Improvements When preparing a post for publication, hints about media file visibility are now displayed. Before publishing, the creator will be able to see which photos or videos will be visible to all users and which will remain locked. If age restrictions are enabled while creating a post, an adult content warning will automatically be added to the post cover. The new version improves chat stability when switching between accounts. Unread message indicators, notification badges, chat start requests, chat deletion, and various message actions have also been fixed. Additionally, text messages can now be copied. Special attention was given to image and media file handling. On Android, an issue that could cause images to display incorrectly after cropping has been resolved. Media file uploading has also been fixed, so all selected images should now display correctly. Scrolling after unlocking paid messages has been improved, and the reliability of feed navigation and filters has been enhanced. Delays that could occur when editing posts and Layers have been eliminated. Profile updates, the blocked users list, and navigation between different sections of the app have been fixed. In addition, the team has fixed UI and text rendering across different screen sizes and languages. Accidental repeated report submissions on multiple taps have been resolved, and the performance of notifications, informational messages, and bottom sheets has been improved. A number of visual issues related to media counters, badges, buttons, and text labels have also been fixed.
