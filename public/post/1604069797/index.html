🚧 Изменение организации дорожного движения в Новороссийске Внимание водителей. С целью обеспечения безопасности дорожного движения, в рамках мероприятий по ликвидации очаговой аварийности, на пересечении ул. Школьная/ ул. Ленина, тер. Цемдолина выполнено обустройство дополнительной полосы для поворота налево. До начала учебного года на данном участке будет выполнена установка дополнительных секций светофора для регулирования движения при осуществлении поворота налево. Ранее на данном участке выполнены мероприятия по обустройству шумовых полос. Будьте внимательны и осторожны! Берегите свою жизнь и жизнь других людей!
