🔥 Полная настройка AmneziaWG 2.0 на роутере Keenetic Хотите, чтобы VPN работал сразу на телевизоре, приставке, компьютере, смартфоне и других устройствах без установки приложения на каждое из них? Тогда эта инструкция для вас. ⏱ Время настройки: 10–15 минут 📋 Что понадобится Перед началом убедитесь, что у вас есть: ✅ Роутер Keenetic с KeeneticOS 5.1 или новее ✅ Зарубежный VPS (Ubuntu 22.04 или Ubuntu 24.04) ✅ Компьютер с установленным приложением AmneziaVPN 💡 Что такое VPS? VPS — это удалённый сервер, который станет вашим личным VPN-сервером. Именно к нему будет подключаться роутер, а весь интернет-трафик будет проходить через него. ① Арендуем VPS Если сервера ещё нет — арендуйте его у любого VPS-провайдера. https://my.adminvps.ru/aff.php?aff=30713 Промокод ДневникСисадмина скидка 60% на месяц Лучше выбирать сервер в одной из стран: 🇳🇱 Нидерланды 🇩🇪 Германия 🇫🇮 Финляндия 🇵🇱 Польша После покупки вы получите: • IP-адрес сервера • пользователя root • пароль или SSH-ключ ⚠️ Эти данные понадобятся для установки VPN. 📷 Скриншот №1: письмо или панель VPS с IP-адресом, логином и паролем. ② Устанавливаем AmneziaVPN на сервер Установите приложение AmneziaVPN на компьютер и запустите его. https://amnezia.org/ru/downloads Нажмите: ➕ Добавить сервер Выберите: Self-hosted VPN (Свой сервер) Введите: • IP-адрес VPS • SSH-порт 22 • пользователя root • пароль Нажмите Подключиться. Далее ничего делать не нужно — AmneziaVPN автоматически установит всё необходимое на сервер. ⏳ Обычно это занимает 2–5 минут. 📷 Скриншот №2: окно подключения к своему серверу. 📷 Скриншот №3: процесс установки. ③ Устанавливаем AmneziaWG 2.0 После завершения установки откройте созданный сервер. Выберите: Установить протокол Затем: ✅ AmneziaWG Дождитесь окончания установки. 📷 Скриншот №4: список протоколов с выбранным AmneziaWG. ④ Создаём конфигурацию Откройте установленный протокол AmneziaWG. Выберите: Поделиться VPN ↓ Оригинальный формат AmneziaWG ↓ Сохранить файл Будет скачан файл вида: amneziawg.conf ⚠️ Не изменяйте этот файл вручную. 📷 Скриншот №5: меню экспорта конфигурации. ⚠️ ВАЖНО! AmneziaWG 2.0 работает только на KeeneticOS 5.1 и новее. Если на роутере установлена версия 5.0.x или ниже, импортировать новый конфигурационный файл бессмысленно — VPN работать не будет. Перед началом обязательно обновите прошивку, если ваша модель Keenetic поддерживает KeeneticOS 5.1 или выше. ⑤ Подготавливаем Keenetic Откройте браузер: 🌐 http://my.keenetic.net или 🌐 http://192.168.1.1 Перейдите: Управление → Обновления и компоненты Проверьте: ✅ KeeneticOS 5.1 или новее ✅ установлен компонент WireGuard VPN Если компонента нет — установите его. 📷 Скриншот №6: установленный компонент WireGuard VPN. ⑥ Импортируем конфигурацию Перейдите: Интернет → Другие подключения Нажмите: ➕ Добавить подключение Выберите: WireGuard Затем: Загрузить конфигурацию из файла Выберите ранее скачанный файл .conf. После импорта откройте подключение и включите: ☑️ Использовать для выхода в Интернет Нажмите Сохранить. 📷 Скриншот №7: импорт файла. 📷 Скриншот №8: включённая опция «Использовать для выхода в Интернет». ⑦ Настраиваем политику подключений (рекомендуется) По умолчанию после включения VPN весь интернет дома может работать через VPN. Если VPN нужен только для телевизора, приставки, компьютера или смартфона, лучше создать отдельную политику. Откройте: Интернет → Приоритеты подключений Создайте новую политику, например: VPN Добавьте в неё только соединение AmneziaWG. После этого назначьте её только нужным устройствам. Например: 📺 Smart TV 📦 Android TV 💻 ПК 📱 Смартфон 🎮 Игровая консоль Остальные устройства продолжат использовать обычный интернет. 📷 Скриншот №9: создание политики. 📷 Скриншот №10: назначение политики устройству. ⑧ Проверяем работу Если всё настроено правильно, в статусе подключения появятся: 🟢 Подключено 🔄 Handshake 📈 Передача данных 🎉 Готово! Теперь роутер автоматически подключается к AmneziaWG 2.0 Если инструкция оказалась полезной — поставьте ❤️ 💬 Если возникли вопросы — пишите в комментариях, поможем разобраться. #Keenetic #AmneziaVPN #AmneziaWG #WireGuard #Computerchik
