В новостях мелькает один из самых милых ИИ-запусков — «Авито» запустил се…

В новостях мелькает один из самых милых ИИ-запусков — «Авито» запустил сервис ХвостРадар для поиска потерявшихся питомцев. Сервис — разработка «Авито», созданная вместе с волонтерами. «ХвостРадар» будет искать кошек и собак по фотографии: технологии компьютерного зрения сравнят снимок с объявлениями о найденных животных, учтут место и время пропажи, а если найдут совпадение — предложат сразу связаться с человеком, который разместил объявление. За последний месяц через «Авито» домой вернулись больше 400 питомцев. Теперь шансы найти потеряшку в первые часы после пропажи должны стать еще выше. Одно из самых полезных применений ИИ за последнее время 😁
