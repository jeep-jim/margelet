🏆 Мобильное приложение Циан заняло первое место в независимом исследовании Роскачества Эксперты протестировали приложения для поиска недвижимости по 111 критериям: оценивали поиск и фильтры, работу с карточками объектов, управление объявлениями, безопасность, удобство использования и другие параметры. По итогам исследования приложение Циан получило наивысшую итоговую оценку как на Android (4,43), так и на iOS (4,45). Исследование проводилось по методике, основанной на государственном стандарте сравнительных испытаний мобильных приложений ГОСТ Р 702.5.009-2024. Для профессионалов рынка это подтверждение того, что пользователи получают удобный инструмент для поиска жилья, а объявления — дополнительную точку контакта с аудиторией 🔑 Подробнее с результатами исследования можно ознакомиться на сайте Роскачества 🖇
