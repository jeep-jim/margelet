Замена ПО все чаще становится для компаний возможностью пересобрать рабоч…

Замена ПО все чаще становится для компаний возможностью пересобрать рабочие процессы. Так, производитель упаковки ДАНАФЛЕКС при переезде на решения Яндекс 360 для бизнеса решил интегрировать в виртуальный офис 22 внутренних веб-приложения. Это позволило собрать информацию из разных корпоративных систем в одном месте, чтобы избавить сотрудников от постоянных переходов между сервисами. На базе API Яндекс 360 создали систему уведомлений, которая собирает события из всех внутренних приложений и направляет их в Почту. Всего на сервисы Яндекс 360 перевели коммуникации более 1500 сотрудников. Миграция принесла финансовый эффект: ежегодные расходы на лицензирование ПО сократились на 78%.
