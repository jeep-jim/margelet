#Design #GitHub情报 #iOS #APP 🏞 介绍两个把数字内容转化为纸张印刷 / 独立出版物（ZINE）视觉形式的项目 最近 X 上流行几种视觉效果，看起来蛮有质感。本质上来讲，它们还是通过特定的提示词将输入的视觉内容转化为纸张印刷 / 独立出版物（ZINE）的视觉形式。从设计风格来看，都受到日本独立出版、孔版印刷和复古编辑设计的影响 1️⃣ tone：紙に刷ったような写真加工 🔗：App Store | X 👉 Features - 模拟半色调网点（Halftone） - 模拟套色偏移（Misregistration） - 加入纸张纹理 - 可自定义调节印刷颜色、油墨浓度、颗粒度等 tone 强调的是一种「调调」：让照片看起来像被印刷出来。它不像手机摄影那样高清、干净，而是加入了带有旧时独立出版风格的一些特征，将最终生成的照片赋予视觉上的物理效果 2️⃣ GC Minimal Zine Poster 🔗：GitHub | X 👉 Features - 一个小型、可被清楚表现的主体或视觉组合 - 3:5 比例的仿旧纸张画布 - 70% – 90% 的留白 - 衬线、打字机或等宽字体 - 一个清晰可见的高饱和度色彩锚点 - 复印、孔版印刷、网点、凸版印刷或扫描纸张的瑕疵与质感 - 安静的日式／韩式独立 ZINE 或极简编辑设计氛围 项目本质上是一个开源 Skill，它会把主题、句子、物件、情绪、文章构想、照片或内容简报，转化为一张安静、极简的 ZINE 风格编辑海报所需的提示词，并生成对应的位图图像 开发者设计的初衷，会避开商业广告式布局、光亮样机、电影感布光、3D 渲染、霓虹、密集拼贴簿，以及大段整齐的文字，欢迎试试效果是不是你想要的 📘 关联阅读： 1️⃣ Tone：从自然摄影中，找到你的色彩灵感 2️⃣ 分享近期火热的几个「文生图」网页 频道：@NewlearnerChannel
