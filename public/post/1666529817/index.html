Dini hari di Desa Pranggang, Kecamatan Plosoklaten, Kabupaten Kediri, men…

Dini hari di Desa Pranggang, Kecamatan Plosoklaten, Kabupaten Kediri, mendadak mencekam setelah rumah seorang janda berinisial EP (37) dilalap api, Kamis (16/7/2026) sekitar pukul 01.30 WIB. Warga yang mendengar suara riuh dan teriakan minta tolong langsung keluar rumah, dan saat itu api sudah tampak dari bagian depan bangunan. Tetangga korban, Narko (38), menuturkan api awalnya masih kecil, namun cepat membesar dalam hitungan menit. Warga pun bergerak cepat memadamkan api dengan peralatan seadanya, termasuk mengambil air dari rumah warga sekitar karena pasokan air di rumah korban sudah tidak tersedia. Dari keterangan di lapangan, kebakaran itu kuat dugaan dipicu oleh mantan suami korban yang datang sebelum api membesar. Orang tersebut disebut sempat menyiram bahan bakar ke motor Honda PCX milik korban, lalu api menjalar ke bagian rumah dan membakar sejumlah perabotan di dalamnya. Plt. Kepala Satpol PP Kabupaten Kediri, Kaleb Untung Satrio Wicaksono, mengatakan laporan kebakaran diterima sekitar pukul 02.05 WIB. Tim Damkar Pos Pare kemudian tiba di lokasi pukul 02.20 WIB dan baru berhasil memadamkan api sekitar pukul 04.30 WIB setelah berjibaku lebih dari dua jam. Kapolsek Plosoklaten AKP Didik Suryono juga membenarkan kejadian tersebut dan menyebut pihaknya masih mendalami kasus ini. Beruntung, korban yang tinggal bersama dua anaknya selamat tanpa luka, meski kerugian ditaksir mencapai sekitar Rp1 miliar.
