Ich werde die nächsten Tage ein Dezentrales Multi Server Konzept vorstellen - welches faktisch nicht abzustellen ist. Aus den Schwächen von Telegram lernen und die Stärken übernehmen Eine Zentrale Multi Server RTMP Plattform - wo jeder Streamer sein eigener Herr über seinen Stream ist. Keine Zensur von YouTube etc. Das ganze kommt, zusammen mit einem Web Editor, der mehr Funktionen bietet, als zum Beispiel WordPress - inklusive ohne Zusatzkosten für Plug ins - keine Abos für Sachen die man braucht. Dieser Web Editor arbeitet ohne Abhängigkeiten - von Google Bing etc. Kein Tracking, keine Cookies. Sehr schwierig angreifbar, da es sich um eine Single File HTML Lösung handelt . Kein CMS- Extrem schnell - sehr gutes SEO - geschlossener Mitglieder Bereich mit Chatraum. Eigene DLIVE ähnliche Funktionen mit ORANGEN 🍊 , statt Zitronen (BodoLino‘s) Lasst Euch überraschen Die Webseite Schiffmann.TV ist bereits mit diesem Editor komplett realisiert. Extrem schnelle Ladezeiten, Produkt Bibliothek für affiliate Marketing bereits inklusive Die gesamte Seite besteht aus kleinen Blöcken so genannten Sektionen. Alle Sektionen können ein separates CSS bekommen. Ein Vorstellungs Video kommt in Kürze Nach drei Wochen bereits ohne Anmeldung im Suchindex der großen Suchmaschine
