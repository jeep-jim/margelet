В Германии разрешили выпуск топлива для АЭС по технологиям «Росатома» Решение раскритиковали власти Нижней Саксонии, которые назвали сотрудничество с «Росатомом» политически ошибочным. При этом работу предприятия разрешили только при соблюдении дополнительных требований безопасности. Министерство окружающей среды федеральной земли Нижняя Саксония разрешило расширить завод по производству ядерного топлива в городе Линген. На предприятии будут выпускать тепловыделяющие сборки для реакторов российского типа по технологиям компании ТВЭЛ, которая входит в «Росатом». Об этом пишет Die Zeit. Завод принадлежит компании Advanced Nuclear Fuels (ANF), входящей во французскую группу Framatome.
