🚌 Путешествия по Тульской области становятся комфортнее По моему поручению в регионе начал курсировать туристический автобус. Его первый рейс состоялся сегодня — участники отправились на Куликово поле. Наша задача — сделать туристические маршруты доступнее для жителей и гостей региона. Не у всех есть возможность добраться до удаленных достопримечательностей на личном транспорте, поэтому запускаем новый формат экскурсионных поездок. Первым направлением стало Куликово поле — место, где создавалась история нашей страны. Участники посетили Музей Куликовской битвы, познакомились с экспозицией «Сказание о Мамаевом побоище. Новое прочтение», увидели Красный холм с памятником Дмитрию Донскому и храмом Сергия Радонежского. После апробации маршрутов график поездок будет опубликован на туристическом портале визиттула.рф. Проезд для пассажиров будет бесплатным, оплачивается только экскурсионная программа. Развиваем туристическую инфраструктуру и открываем жителям и гостям региона новые возможности для путешествий по Тульской области. Это одна из задач национального проекта «Туризм и гостеприимство».
