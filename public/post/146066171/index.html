#互联网观察 ▎ OpenAI Codex 存在异常日志写入问题 问题主要出现在长期运行任务和流式任务场景下，Codex 会持续向本地的 ~/.codex/logs_2.sqlite 及其 WAL 文件写入 TRACE 日志，导致磁盘写入量异常增加。部分开发者监测到 SSD 写入量远高于正常水平，甚至担心会加速消费级 SSD 的寿命损耗。 该问题最早于 6 月中旬被提交至 Codex GitHub 仓库，随后大量用户反馈复现。除了磁盘写入异常外，还有用户遇到 WAL 文件持续膨胀、磁盘空间被快速占用以及 Codex 响应速度下降等情况。 OpenAI 随后在 Codex 0.142.0 版本中加入修复措施，并关闭了相关 Issue。升级后的用户普遍反馈写盘频率已经明显下降，WAL 文件增长速度得到控制。 不过，新的反馈显示问题并未彻底消失。就在最近，仍有开发者提交新的 Issue，表示 logs_2.sqlite 和 WAL 文件依然持续增长，只是增长速度相比旧版本已经大幅降低。 如果你正在高频使用 Codex，建议检查： du -sh ~/.codex ls -lh ~/.codex/logs_2.sqlite* 同时确认当前版本是否已经升级至 0.142.0 或更高版本。 目前来看，Codex 的高频日志写盘问题已经得到缓解，但距离完全解决仍有一定距离。对于长时间运行 AI Agent、持续执行自动化任务的用户来说，仍值得关注本地磁盘写入情况。 频道 @AppDoDo 官推 APPDOTG
