六月，Firsto 挺过了暑期淡季 六月对 Firsto 来说，不好打。 刚开始就连续 5 天零订单。 每天打开后台，访问量还在，但就是没人下单。 那几天我心里其实有点发毛。明知道平台型产品收入会波动，但真遇到连续鸭蛋，还是会忍不住想：是不是哪里出了问题。 后来想明白了：国外已经开始放暑假。 整个海外市场进了"夏日淡季"，这种时候能把基本盘守住就不算差。 好在月底回了一点血。 靠着一篇 Guest Post 和一个产品 Review 的进账，六月收入最终落在 860 刀。 比五月大概少了 5%。 我对这个结果能接受 整个六月，Firsto 几乎没做什么新功能。 不是没想法，是越来越觉得：对一个已经跑起来的产品发布平台来说，功能没那么缺。 更缺的是内容、流量，还有被看见的机会。 淡季里客户还愿意为 Guest Post 和评测买单，本质上买的是平台的长期权重。 所以七月我大概率不会继续猛加功能了。 我想把时间更多投到内容建设上。 买了个新域名，试水新生态 六月还是没忍住，又买了一个新域名。 不过这次不是再挖一个大坑，而是给自己搭了个练习站。 本质上是一个 Google TTS 的套壳产品。 我真正想练的是整套技术栈： Cloudflare Workers Cloudflare D1 Cloudflare R2 以前我一直用 Next.js 部署。 这次算是第一次把一个小应用完整跑在 Cloudflare 的生态里。 体验比我预想的顺手。 部署简单、成本低，对这种轻量 Web 应用来说确实舒服。 更意外的是，这个几乎没做推广的小站，已经来了 3 个注册用户。 当然，营收还是 0。 我现在的想法很直接：哪天真出现第一个付费用户，我再开始认真做 SEO，把关键词一点点铺开。 在没有收入之前，它就先当我的实验田。 但有一点我基本确定：这套技术栈以后会成为我做 Web 产品的默认选择。 也放弃了一些东西 去年六月，我一口气买了四个域名。 一年过去。 直到续费提醒弹出来，我才发现自己已经完全不想继续做它们了。 最后一个都没续费。 以前我总觉得，域名一年也没多少钱，先留着，万一哪天用得上。
