Yandex B2B Tech представила универсального ИИ-агента для бизнеса на базе Yandex AI Studio. Для сотрудников компаний чат с ним станет единым интерфейсом для взаимодействия с корпоративными сервисами и привычными рабочими инструментами вроде Excel. По оценке компании, агент сможет автоматизировать 30-50% задач офисных сотрудников. Например, он умеет готовить конспекты встреч, пересказывать документы, сравнивать коммерческие предложения, оформлять закупки, заполнять договоры по шаблону и многое другое. С этим решением бизнесу больше не нужно будет использовать множество отдельных ИИ-сервисов. Для более специфических сценариев агента можно научить новым навыкам, рассказав ему процесс решения задачи. Запуск продукта запланирован до конца сентября этого года.
