Eastern Sabah Security Command (ESSCOM) membongkar pelbagai aktiviti meny…

Eastern Sabah Security Command (ESSCOM) membongkar pelbagai aktiviti menyalahi undang-undang menerusi operasi bersepadu selama dua hari di beberapa lokasi sekitar Sandakan. Operasi pada 29 hingga pagi tadi itu menyaksikan 25 pendatang asing tanpa izin (PATI) ditahan, selain tindakan penguatkuasaan, rampasan dan kompaun membabitkan nilai keseluruhan RM433,077.
