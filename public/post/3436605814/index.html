Eastern Sabah Security Command (ESSCOM) membongkar pelbagai aktiviti meny…

Eastern Sabah Security Command (ESSCOM) membongkar pelbagai aktiviti menyalahi undang-undang menerusi operasi bersepadu selama dua hari di beberapa lokasi sekitar Sandakan.
